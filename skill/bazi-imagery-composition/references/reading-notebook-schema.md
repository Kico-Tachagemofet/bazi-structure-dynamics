# 轻量 Reading Notebook

`reading-notebook.md` 是 Render 前唯一的现实判断底稿。它可以自由组织，但每个专题应包含以下内容：

## 专题块

### 核心结论

先写主要方向和现实层级，不以性格开头。

### 形成链

说明：

- 调用的原局主链与竞争链；
- 十神怎样传递；
- 天干体现什么动作；
- 地支提供什么场景、根基或阻力；
- 藏干在哪一层参与；
- 柱位把它落到什么人事范围。

### 现实画面

写清动作、任务、制度、关系或载体如何兑现，必要时比较一至三个候选。具体身份不够强时停在领域性质和核心动作，不退回性格。

### 优势、代价和切换

说明怎样成事、附带什么消耗、什么条件加强或反转，以及最强替代解释。

### 核验

给一至数个命主能直接核对的具体表现。核验不是问卷，也不要求逐条回复。

## 岁运块

`timing-notebook.md` 中每年独立记录：原局保留、新增干支、主链变化、现实倾向、强度／可控性／期限。不得把十年综述替代逐年判断。

## 禁止

- 不生成 claim ID、judgment ID、coverage marker 或 receipt；
- 不为每个字段写固定段落；
- 不用同一“压力—资源—输出”段复制到所有专题；
- 不让免责声明和条件句淹没核心判断。
