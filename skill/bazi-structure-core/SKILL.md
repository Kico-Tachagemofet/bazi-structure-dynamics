# 八字 Structure Core

本技能只做技术结构，默认产物是 `structure-notebook.md`。

## 分析

1. **月令、旺衰与承载**：看司令、季节、根气、透藏、生克泄耗与调候；分开客观过程、日主承载和主动启停能力。
2. **重要关系**：只记录实际命中且会改变判断的天干生克合、地支合冲刑害破、三合方会与重复支。说明它们如何影响本气、藏干、根气和路线。
3. **十神竞争**：说明谁推动、承接、制约、争夺或改道，同一节点服务哪些相反路线，结果流向哪里。
4. **格局与路线**：比较最有解释力的一至三个候选，写成立依据、最弱环、客观产出、日主成本和改判条件。
5. **用神**：分开格局需要、病药制化、扶身承载、调候和备用路线，写清作用、损伤与去处。

合不自动化，冲不自动开库，重复支不自动等于自刑；有根和五行齐全也不等于路线畅通。

## 结构笔记

至少包含盘面与月令、旺衰承载、关键干支关系、十神完整主链、格局候选、用神次序、失败路线、客观成果与日主成本，以及会改变后文的真实未决项。

最后只列下游可以调用的技术接口，例如哪些十神路线成立、哪些干支藏干参与、各柱位承载什么范围、哪些条件会触发改道。不要提前写“适合某职业、学历偏高、婚姻如何、家庭怎样”等生活 verdict；这些由 fresh writer 根据完整 reading pack 独立形成。

## 岁运

固定原局仍在运行的保证，再说明大运／流年新增干支实际形成的关系、受影响路线、强度和持续范围。这里只写结构变化，不预写具体事件。用户要求逐年时，各年仍可在一份结构时间笔记中独立成节。

四柱事实、司令、主要关系或主链存在会反转结论的矛盾时停止；不影响主结论的流派权重差异记录后继续。
