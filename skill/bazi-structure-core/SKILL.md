# 八字 Structure Core

本技能只做技术结构，默认产物是 `structure-notebook.md`。

## 分析要点

1. **月令、旺衰、燥湿与实际传力**：
   - 看司令、季节、根气、透藏、生克泄耗与寒暖燥湿；
   - **必分“名义关系”与“有效传力”**：检查燥土脆金 vs 湿土生金、土厚埋金、冻水难生木、火旺木焚、隔柱阻隔与合绊占用；分清“存在接口”与“能稳定承接的主通道”；
   - 当且仅当原局确实存在“客观结构可运转但日主承载吃紧”或相反张力时，分开写客观产出、日主承载与主动启停能力，不把单盘特征强行套给所有命局。
2. **重要干支关系与藏干不对称胜负**：
   - 只记录实际命中且会改变判断的天干生克合、地支合冲刑害、三合方会与重复支；
   - **冲中藏干必比援军**：四墓相冲（辰戌、丑未）或地支相战时，依《千里命稿》原则先看本气激起，再按**得令、众寡与同党援军**分别裁定各藏干实际留存与站队（例如一藏干若背靠同党强支而对手孤弱受压，则不仅不被克尽，反可并入同党增势）；
   - 合不自动化，冲不自动开库，重复支不自动等于自刑；“支破”在《子平真诠》《千里命稿》中无专门定义，不得作为主裁决依据。
3. **十神竞争与先后来路**：
   - 说明谁推动、承接、制约、争夺或改道，同一节点服务哪些相反路线，以及年→月→日→时先后位置如何改变生克与救应结果。
4. **格局成败与路线**：
   - 比较最有解释力的一至三个候选，写成立依据、格局清浊高低、最弱环与改判条件；明确区分古典月令用神（格神）与现代功能补救用神。
5. **用神次序与失败路线**：
   - 分开格局需要、病药制化、扶身／抑身、调候与备用路线，写清每个用神在原局是“得力可用”“有用受掣”还是“有口难传”。

## 结构笔记

`structure-notebook.md` 至少包含：

- 盘面、月令司令与旬空基线；
- 逐节点力量、透藏与原局实际传力状态；
- 关键干支关系仲裁（含冲中藏干各自胜负与未成半合／半会的实际气势影响）；
- 十神完整主链与竞争路线；
- 格局候选、清浊高低与用神次序；
- 主要失败路线与真实未决项；
- 岁运结构接口（见下）；
- 下游可调用技术接口清单（哪些路线成立、哪些节点传力受阻、各柱位承载什么宫位／时间段、哪些干支开关会触发改道）。

**严禁事项**：结构笔记**绝对不得预写**家庭、学历、职业、财运、婚姻、健康等生活结论（哪怕写成简短的“带入专题锚点”也不允许）；所有生活判断留给全新上下文的 `$bazi-render` 独立完成。

## 岁运接口

- 先固定原局不变的底层保证，再写大运／流年新增干支实际改变了哪条关系、通量、燥湿与强弱；
- **连贯对照**：分析当前大运时，须简明对照**前运与后运**的结构切换，交代运势起落拐点与干支分管节奏（如韦千里前五年干七支三、后五年支七干三折衷法）；
- **敏感开关**：标出本运中最易引爆原局病灶或彻底激活喜用的流年干支条件（例如补齐原局缺一字的三合/三会、冲合用神、穿害关键湿燥土等）；
- 这里只写结构变化与触发条件，不预写未授权的具体年份事件。

四柱事实、司令、主要关系或主链存在会反转结论的矛盾时停止；不影响主结论的流派权重差异并列记录后继续。
