# 八字 Source Lookup

Source Lookup 把需要的材料送到结构层和 fresh writer，不负责证明读过多少文件。

按需使用：

- `../bazi-structure-dynamics/references/source-index.md`
- `../bazi-structure-dynamics/references/ziping-zhenquan-source-map.md`
- `../bazi-structure-dynamics/references/ruojing-course-source-map.md`
- `references/deep-card-index.yaml`

## 结构模式

读取会改变旺衰、格局、合冲刑害、墓库、人元、通关和制化的规则，写入 `source-notes.md` 的结构依据。

## Reading-pack 模式

用户确认范围后，完整读取本盘实际出现并参与主要路线的五行、十神、天干、地支、重要藏干，以及用户指定大运流年的相关卡片。把底层动作、状态变化、材料、场所、人物关系和载体候选补入同一份 `source-notes.md`，并把实际使用的卡片复制到 `reading-pack/materials/`。

来源笔记提供候选和来源边界，不替 fresh writer 排名最终职业、学历、婚姻结果或事件。Deep Card 不改写 Structure Core 的旺衰、格局和作用关系。

## 输出

`source-notes.md` 包含实际读取来源、结构规则、符号与状态材料、可比较的现实载体候选，以及真实来源冲突或缺口。普通命例到此结束，不生成逐卡收据或专题 packet。
