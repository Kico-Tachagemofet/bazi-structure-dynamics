## 1. Core process

丁继承火的“炎上”，在《千里命稿》的丙丁配对里被称为**阴火、薪傅之火**。本卡把它理解为光热借助薪材、媒介或具体焦点得到承载和传续的过程：**聚焦、维持、传递、温养、显影并促成形质转化**。

灯烛、炉火、香火、火种、舞台焦点、精细加工与烹饪，都是这一过程可能落实的载体，不是丁的固定身份。丁也不等于微弱小火；来源持续、媒介合适、热量集中时，薪傅之火可以真正改变物质形态。

## 2. Derivation path

```text
火曰炎上
→ 光热上升、照明、显露并推动转化
→ 丁为阴火、薪傅之火，优先观察光热怎样附着于薪材、媒介或焦点而传续
→ 候选动作：聚焦、续燃、传递、温养、显影、精细加热、改变形质
```

《千里命稿》先批评“丙为太阳、丁为灯烛”等固定比喻，再以融和之气／薪傅之火重建丙丁区别。因此灯烛是高匹配载体，却不能反过来把丁定义成小、弱、隐秘、女性化或只能在幕后。

原书用丙丁对庚辛的作用说明气／质差别：阳和可以改变秋天肃杀之气，却未必损坏人间金铁；薪傅之火能作用于金属形质，却未必改变肃杀之气。这是一则作用维度示范，不是“同阴阳才能实克”或“阳克阴永远只是形式抑制”的普遍结构规则。

## 3. 与丙火的配对差异

| 维度 | 丙的优先观察 | 丁的优先观察 |
|---|---|---|
| 来源定义 | 阳火，融和之气 | 阴火，薪傅之火 |
| 过程位置 | 形成开放、外布、环境性的光热场 | 光热附着于薪材、媒介或局部焦点而传续 |
| 动作候选 | 辐射、照明、升温、公开、带动整体环境 | 聚焦、维持、传递、温养、显影、精细加热 |
| 载体候选 | 日光、大火、公共照明、舞台、传播、能源场 | 灯火、炉火、烛火、火种、窑炉、局部加工与媒介传递 |
| 核心条件 | 光热范围、来源、遮蔽与环境交换 | 薪材／媒介、焦点、续燃、通风与局部承载 |

这不是大火／小火、强／弱、公开／秘密的固定二分。丁可以成为舞台焦点，也可以在持续供给下形成高温窑炉；丙也可能微弱、受遮或只在局部起效。

## 4. Derivation routes

### A. 薪材与传续路线｜优先

- 光热借助薪、油、芯、燃料、电力或其他媒介被保持和传递；
- 火种、小灯与局部热源可以“小而不断”，但没有媒介时也可能熄灭；
- “旺而不烈、衰而不穷”可作为集中度与续燃性的评注候选，不能绕过实际根气和环境裁决。

### B. 聚焦、照明与显影路线｜过程展开

- 把光热集中到一个对象、区域或细节，使其被看见、辨认或进一步处理；
- 可落实为工作灯、舞台焦点、绘画与影像照明、观察、说明、检查、显影；
- 聚焦不等于天生细心，也不自动等于秘密、灵性或洞察一切。

### C. 温养与形质转化路线｜功能展开

- 持续温热、熟化、烧制、烹饪、熔炼、焊接、烧结及细部加工；
- 《千里命稿》“人间金铁之质逢薪傅之火而立化”支持丁火可以实质改变材料；
- 能否真正熔化仍取决于热量、时间、燃料、对象与散失，不是见丁见辛便自动“克掉”。

### D. 媒介、技艺与呈现路线｜现实展开

绘画、表演、美容、陶瓷、烹饪、照明和精细加工，可由“媒介承载—聚焦显影—持续转化”推出。演员也可由丙的公共光场承载；选择丙或丁路线，要看本题强调环境扩散还是局部焦点与技艺媒介。

### E. 外形、感官与身体路线｜候选

- 形态感：清亮、精细、秀扬、暖色、淡红、焦点明确、局部有光；
- 感官候选：视线、光点、温度、细部辨识与清晰呈现；
- 身体功能候选：心血循环、眼目、体温与炎热反应。

具体外貌和疾病仍须身体／外形专题、多重锚点与现实条件。“癸丁冲所以近视”不能作为自动断验。

### F. 物件与场所路线｜现实载体

- 物件：灯烛、灯芯、火苗、香火、打火机、炉灶、窑炉、工作灯、发热器与烧制工具；
- 场所：厨房、工作室、舞台焦点、照明区、美容操作区、陶瓷／冶炼／焊接等集中加热空间；
- 课程中的“新月”主要来自字形与微光联想，只作低权重物象，不能成为丁的核心定义。

### G. 评注与跨体系旁支｜分层保留

- 《滴天髓》“柔中、内性昭融、旺而不烈、衰而不穷”可拆为内聚、清明与续燃状态候选；
- “抱乙而孝、合壬而忠”是拟人化关系表达，不迁成孝顺、忠诚的固定人格；
- 奇门的星之精、六丁玉女、逃亡潜身、丁奇吉凶、宫位神煞与断验不迁入八字；
- 柔妄、不可测识、斤斤计较等道德化或贬义人格标签不迁移。

## 5. State switches

- **得时、有根、薪源与媒介连续**：光热能够稳定聚焦和传续，表现为持续照明、温养、显影或形质转化。
- **火势不大但媒介稳定**：可能小而不断、作用集中；这才是“衰而不穷”可查询的状态，不等于所有丁都持久。
- **热量集中且时间足**：可能真正烧制、熟化或熔炼材料；丁不因阴火身份而天然缺少强度。
- **有火而缺薪／媒介中断**：可能闪烁、间断、需要反复点燃或难以维持焦点，不能直接定为情绪化、没恒心。
- **燃料过多、通风或出口失衡**：可能烟熏、闷烧、过热、执着局部或媒介反过来遮光；不能以“木多生火”自动判好。
- **水参与**：可能调温、相济、合住、阻隔或熄灭，须继承 Structure Core 对数量、位置、通路及丁壬关系的裁决。
- **金为作用对象时**：须区分肃杀之气与实际金属形质，并检查温度、持续时间与承载；不能把原书示范普遍化为阴阳克制强弱口诀。
- **隐藏或可见度低**：可以转成内部温养、幕后技术、局部照明与精细处理，不等于没有作用或必然神秘。
- **被合、被冲、透藏、入墓库或路线占用**：只读取已审计的关系后状态，本卡不重算边、通量、合化或吉凶。

## 6. Candidate expressions

### 性质与动作

聚焦、续燃、传递、温养、显影、照料细部并持续改变形质。失衡时可表现为焦点过窄、反复点燃、媒介依赖、局部过热或烟多光少。

### 外形与身体题

清亮、精细、暖色或淡红、目光聚焦、局部有光、动作细致而有节奏，可作为外形候选；心血循环、眼目、体温和炎热反应可作为身体功能查询。它们都须接身体锚点和状态，不从一个丁字直接定外貌或疾病。

### 学习与工作题

可查询聚焦关键细节、反复打磨、借助具体媒介学习、把模糊内容显影并形成技术成果的路径。工作上先判断是否需要集中照明、持续加热、精细加工、艺术呈现或维护火种，再列烹饪、美容、陶瓷、表演等载体。

### 物件与场所题

灯烛、火苗、香火、打火机、炉灶、窑炉、工作灯、发热与烧制工具，以及厨房、工作室、舞台焦点和集中加工空间，均可成为候选。

## 8. Bridge requirements

每个现实表达记录：

1. `core_process`：调用薪材传续、聚焦显影、温养转化、媒介技艺还是其他路线；
2. `chart_anchor`：由哪个干支、柱位、节点或已冻结路线承载；
3. `post_relation_state`：当前是续燃、聚焦、受阻、闷烧、过热、显影、改质还是尚未显化；
4. `topic_axis`：为什么本题调用性格、外形、身体、学习、职业、财富、关系或物件；
5. `carrier_rank`：candidate／supported／preferred／assertable；
6. `alternative_carriers`：灯烛、炉火、技艺、舞台焦点等竞争载体中，为什么当前一个更符合本题。

本卡不能单独决定丁是否旺、是否为用、是否温柔细心、是否具有灵性或艺术天赋、是否从事美容／烹饪／表演、是否患心眼疾病，也不能单独决定丁壬合、癸丁冲及丁对庚辛的实际作用、合化、损伤程度或吉凶。
