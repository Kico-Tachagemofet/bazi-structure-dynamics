## 1. 古典语义核

《尚书·洪范》先列“一曰水，二曰火，三曰木，四曰金，五曰土”，随后写：

> 水曰润下，火曰炎上，木曰曲直，金曰从革，土爰稼穑。

原文紧接着以咸、苦、酸、辛、甘说明五味对应。此处没有直接讨论命主性格、外形、行业、事件，也没有在本句定义相生相克。

| 五行 | 古典语义核 | 第一层过程候选 |
|---|---|---|
| 水·润下 | 润泽，并有趋下的方向 | 流动、渗透、汇聚、进入低处、滋养 |
| 火·炎上 | 炽热、燃烧并向上升腾 | 升温、发散、照明、显现、引起注意 |
| 木·曲直 | 能弯曲也能伸直，具有生长与成形能力 | 扎根、伸展、形成枝干、柔韧、挺拔 |
| 金·从革 | 能随熔铸、加工而改变形态，最终成器 | 改形、成形、精炼、裁切、取舍、更新 |
| 土·稼穑 | 由种植到收获，使培育过程得以完成 | 承载、养育、消化、转化、积累、落实 |

“从革”先以可改形、可成器为核心；肃杀、裁切、规范、审美加工是后续可展开方向，不反过来缩窄原词。“稼穑”先以培育过程的完成为核心；“使万物开始又结束”只作课程扩展，不作为古典原义。

## 2. 方法论工作模型

本卡采用“先看运行过程，再找物质载体”的工作模型：五行不只等于五种材料，具体物件也可能承载不同的过程特征。

这是一种课程解释和当前架构归纳，不冒充《洪范》逐字定义。它只用于取象展开，不能改写 Reader 已冻结的五行事实。例如水蒸气可以帮助理解升腾动作，但不能因此把八字中的壬癸重新判成火。

```text
古典语义核
→ 阴阳与具体干支怎样表达该过程
→ 本盘关系后状态怎样让过程持续、受限、改道或换形
→ 十神、柱位与问题中心赋予什么功能
→ 在多个现实载体中选择当前最贴合者
```

## 3. 状态开关

同一五行不是只有“旺＝正面、衰＝负面”两格。至少比较：

| 开关 | 观察问题 |
|---|---|
| 得时／有根／有承载 | 该过程是否连续、稳定、能够完成 |
| 受生 | 获得材料或动力后是有效展开，还是供给过多而拥塞、漂浮、过度扩展 |
| 受制 | 被塑形、修剪、定界，还是功能受抑、形质受损 |
| 过盛 | 原过程是否失去边界：木蔓延、火耗散、土壅滞、金过切、水漫流只作思考方向，不能自动判凶 |
| 无根／无通道／无去处 | 象意是否只停在表层、间歇、愿望或局部载体 |
| 合冲刑害、透藏、入墓库 | 完全继承 Structure Core 的关系后状态，本卡不自行裁决 |

### 五行各自的状态变化示例

- 木：有根有序时可形成持续生长；扩展无依时可能枝蔓、漂浮或难以成材。
- 火：有燃料和承载时可以持续照明、传播和显化；缺承载时才可能迅速升起又迅速耗散。
- 土：承载与转化顺畅时能把投入送到成果；过厚或通道受阻时可能积压、迟滞。
- 金：得到合适材料和加工条件时能够改形成器；过度裁切或形质不足时可能只剩形式边界。
- 水：有通道和去处时能够润泽、流通、汇聚；失去边界或出口时可能漫散、停滞或潜藏。

“火虚、不持久”因此只属于“缺承载／耗散过快”的状态候选，不是火的固定本性。

## 4. 课程解释候选：不进入核心定义

奇门课程把“生”概括为发散，把“克”概括为收敛，并提醒相生不必然好、相克不必然坏。它可以帮助提出问题，但不能充当八字结构定义：

- 相生时可检查输送、展开、诱发、供给与泄耗；
- 相克时可检查限制、塑形、抑制、占用、形式约束与形质损伤；
- 实际发生哪一种效果，必须由 Structure Core 的目标承载、通量、阴阳关系、距离、竞争和去处裁决。

本卡不得用“生＝发散、克＝收敛”直接决定边、强弱、吉凶或谁居主导地位。

## 5. Candidate expressions 与现实载体

以下均为可正常使用的候选，不是禁词：

| 过程 | 外形候选 | 学习／行为候选 | 职业性质候选 | 物件／场所候选 |
|---|---|---|---|---|
| 曲直 | 高挑、修长、舒展、柔韧、挺拔 | 生长式理解、搭框架、持续扩展 | 培育、规划、连接、结构设计 | 植物、纤维、长形结构、书籍纸张 |
| 炎上 | 上扬、鲜明、易被看见 | 快速呈现、表达、传播、启发 | 前台表达、宣传、影像、电子、热能 | 光源、电子设备、热源、展示媒介、证件 |
| 稼穑 | 厚实、稳定、承载感 | 消化、反复吸收、积累、落地 | 运营、照料、平台、建设、仓储 | 房屋、土地、仓库、基础设施、容器 |
| 从革 | 骨架、棱角、精细、修饰感 | 筛选、校订、形成标准、改造 | 加工、决策、规则、金融、审美成形 | 金属、器具、首饰、刀具、制度文本 |
| 润下 | 流线、圆润、柔动 | 渗透理解、搜集、联想、深潜 | 信息、流通、研究、服务、运输 | 水体、液体、通道、网络、隐蔽空间 |

教育、电子、金融、研究、运输等不是《洪范》原句，也不是五行卡自身可激活的职业单元。它们只作为领域载体层的检索线索；须经十神功能、柱位、完整路线、日主承载、现实结果与竞争载体等 gates 后，才可进入 finding。证据确已闭合时可以明确给出优先候选，不要求机械附加“但也不一定”。

## 6. Bridge requirements

现实载体从候选进入 finding 时，记录：

1. `core_process`：调用的是哪一层五行过程；
2. `chart_anchor`：由哪个干支、柱位、节点或路线承载；
3. `post_relation_state`：当前是持续、受压、改道、成形还是未显化；
4. `topic_axis`：为什么本题调用外形、学习、职业、物件或人物载体；
5. `carrier_rank`：candidate／supported／preferred／assertable；
6. `alternative_carriers`：若存在，为什么不优先。

外形题须比较身体／日主体象和全盘形态；职业题先写工作性质，再由领域载体层比较行业、岗位、工作内容和收益渠道。多个独立锚点一致时可直接说“更可能高挑挺拔”或指出已经胜出的职业载体；不得因为单个五行象意就把行业候选升级为结论。

## 8. Cannot decide

本卡单独不能决定某五行在本盘的旺衰、可用性、合化、通量、格局、吉凶和唯一现实载体，也不能把物理材料的动作重新写成命盘五行事实。

这是一个统一边界，不在每个候选后重复列“不能推出什么”，以免诱导模型过度防御。
