## 1. 地支不是缩小版天干

天干偏显性发用与外在动作，地支偏**时令季节、生活场景、空间容器与多层人元库存**。看地支切忌压成“天干能做事、地支不能做事”，也切忌把一个支直接等同于它的本气天干。

## 2. 四层显化模型（防把藏气直接当既成事件）

| 层级 | 核心问题 | 典型落笔方式 |
|---|---|---|
| **场在（field）** | 这个支自带什么季节寒暖、环境氛围与生活容器？ | 问居所、环境、身心体感与背景气场时可直接调用，不要求藏干透出 |
| **气在（qi）** | 支中本／中／余气哪些只是根基、库存或同党环境供给？ | 替透干撑根、作幕后底气，或潜伏于内部，不等于已经出面成事 |
| **用起（function）** | 哪个藏干在原局或岁运里真正进入生克主链做功？ | 须有得令、透清、强同党、近贴或岁运引动支撑，不因同支一气起用而三气齐发 |
| **果显（result）** | 场域或功能是否已接到本题的现实结果与具体载体？ | 须与十神功能、柱位宫位、格局成败和岁运阶段闭合 |

## 3. 静态藏干、司令时序与冲合墓库铁律

1. **静态藏干与司令分开**：每支藏干及本／中／余气层级一律服从 Reader 标准（《千里命稿》表）；月令人元司令（徐乐吾评注表）只用于月令用事校正，不改写静态藏干，且日数本身“未可执着”。
2. **墓库不机械论“逢冲必发”**：依《子平真诠》第十七篇，辰戌丑未终以土为主，冲首先激土旺，不等于自动打开财库官库放出全部藏干。
3. **冲中藏干必比援军**：依《千里命稿》补充篇，四墓冲或地支相战时，内部藏干胜负由**得令、众寡与全局同党援军**决定——有强援者反而留存并入党势，孤弱受压者才受损难出。
4. **岁运只做 overlay**：原局潜伏的藏干或半合／半会接口，逢岁运透清、补齐或冲合时在对应时间窗重算，覆盖期过即退，不改写原局事实。

## 4. 来源署名

- 《子平真诠》原本第二十七、二十八篇（干支动静、静待透用）及第十六、十七篇（杂气与墓库刑冲）；
- 《千里命稿》地支篇、人元篇、补充篇（地支藏干与冲中藏干胜负法则）；
