- `version`: 0.3

## 1. 核心立场

十神是日主与其他节点之间，由五行生克方向和阴阳同异命名的相对关系。它首先描述同类、输出、经营、约束与输入怎样作用于日主；人物、亲属、物件、职业和事件只是该关系在特定来源框架、柱位、问题中心与关系后状态中的现实载体。

```text
Reader 确定十神名称
→ 锁定本题所论之体与六亲来源口径
→ 枚举参与这一件事的其他十神节点
→ 读取 Structure Core 已冻结的作用关系
→ 在问题中心中选择现实载体与表达强度
```

不得从十神名称直接绑定唯一人物、吉凶或事件；也不得因为同一件事涉及财、官杀、比劫等多个节点，就改换已经锁定的本体身份。

本卡中的人物、亲属、房车、学历、教学、职位等例子用于保留关系功能的现实语境，默认属于 `relational_carrier` 或复合载体检索线索；它们不是见到十神即可激活的候选。具体职业、岗位、正式身份与事件必须另过领域载体推导。

## 3. 《千里命稿》的完整功能索引

原书不是给十神贴单一名词，而是逐项写“能力—利—弊—所喜—所忌”。以下只作读原文的功能索引，不替代 Structure Core 裁决：

| 关系族 | 原书能力索引 | 关系层工作理解 |
|---|---|---|
| 比劫 | 帮身、任官杀、代泄、制财 | 同类力量共同承载，也可能共享、分流或争夺资源 |
| 食伤 | 泄身、生财、制／敌杀、损官 | 日主向外输出，使能量成为表达、成果、延续或作用 |
| 财 | 生官杀、泄食伤、制枭、坏印 | 日主投入力量、经营、调度或承担成本的外部对象 |
| 正官 | 引财、生印、拘身、制劫 | 规则化约束、职责、资格与边界对日主塑形 |
| 七杀 | 耗财、生印、攻身、制劫 | 更直接的压力、竞争、风险与外力冲击；能否转为可用力量须由结构裁决 |
| 印 | 生身、泄官杀、御伤、挫食 | 外部资源进入日主，提供生养、承接、保护、吸收或抑制输出 |

同一种能力在原书中都可能成利或成弊，取决于日主承载、对象力量、制化路线和全局需要。Deep Card 只保留候选语义，不把“伤官制杀”“印能护身”等压成见字必应的规则。

## 4. 五类关系的核心思想与展开

### 1. 同我者｜比劫

- 核心：与日主共享某类资源、立场、能力或活动空间；
- 人物载体：同辈、兄弟姐妹、同事、同类竞争者、合作者；
- 非人物载体：自我投入、同类渠道、共同产权、重复能力、市场竞争；
- 校准：同类可以支持，也可以分流或争夺，取决于资源是否足够、路线是否竞争。

### 2. 我生者｜食伤

- 核心：日主把能量、知识、身体或资源向外生成，形成延续与产出；
- 人物载体：孩子、学生、被照料者；
- 成果载体：作品、表达、方案、产品、教学、表演、技术输出；
- 身体／生活载体：生育、饮食享用、行动释放等须另有题目和结构锚点；
- 六亲口径：韦千里明确以食神、伤官关系族统看子女，以时柱为子息宫；不是只看食神，也不由本卡另分儿女性别。
- 校准：孩子的身份锁定为食伤后，抚养成本可另见财节点，监护规则可另见官杀节点；这些周边关系不把孩子改判为财或官杀。

### 3. 我克者｜财

- 核心：日主能够调度、经营、交换或承担成本的外部对象；
- 人物载体：韦千里以财为妻、不以财为父；其他流派若以偏财为父，必须显式切换来源，不得与韦氏父母取印的口径混用；
- 资源载体：现金、资产、客户、项目预算、经营对象、可变现资源；
- 校准：见财不等于拥有财富。还要看能否承载、是否有去处、是否被争夺、能否真正变现。

### 4. 克我者｜官杀

- 核心：外部规则、职责、压力和边界对日主进行约束与塑形；
- 人物载体：上级、机构、权力者等须随题目判断；韦千里六亲口径以官杀为女命之夫，并以日支为配偶宫；
- 制度载体：职位、资格、法律、合同、考核、风险、截止期限；
- 校准：约束可以形成秩序、资格与担当，也可能超出承载成为压迫或损伤。不能从“克我”直接判坏。

### 5. 生我者｜印

- 核心：向日主输入、保护、庇护、承载、恢复或赋予合法性；
- 人物载体：韦千里明确以印统看父母，并以月柱为父母宫；长辈、老师、照料者属于生养／庇护功能的扩展载体；
- 知识／制度载体：学习输入、证书、文件、授权、名誉背书；
- 空间／物件载体：房子在本题以遮蔽、安顿和承载为所论之体时，可取印；车子在本题以保护、承载和代步支持为所论之体时，也可取印；
- 校准：房、车的十神归属在题目入口处依所论功能锁定。若本题论房产或车辆的资产、价格与交易，则以财为体；后续出现产权规则、贷款或共同争夺，只增加官杀、比劫等参与节点，不把财体改判成官杀或比劫。

## 5. 所论之体锁定：一事多节点，不是一物反复改名

先区分：

1. `topic_body`：本题真正所论的六亲、对象或功能；
2. `body_relation`：它按已声明来源口径对应的十神；
3. `participating_nodes`：参与此事的其他人物、资源、规则或竞争者；
4. `action_edges`：这些节点正在支持、争夺、泄耗、约束还是保护本体。

本体一旦锁定，不因周边节点出现而改名：

| 事件 | 所论之体 | 参与节点 | 关系表达 |
|---|---|---|---|
| 争夺房产 | 房产／产权利益为财 | 共有人或竞争者为比劫；权属规则为官杀 | 比劫争财／夺财；官杀约束财。房产仍是财 |
| 子女问题 | 子女依韦氏口径为食伤 | 抚养资源为财；监护与教育规则为官杀 | 财与官杀围绕食伤发生作用；子女不改判成财或官杀 |
| 婚姻中的竞争 | 妻依韦氏口径为财；夫依韦氏口径为官杀 | 第三者或同类竞争可见比劫 | 比劫作用于妻财／配偶轴；配偶身份不因此改换 |
| 房屋居住支持 | 若题目入口明确论遮蔽与安顿，可锁为印 | 房价、产权和贷款另列财、官杀节点 | 印承担庇护；其他节点作用于居住承载 |

同一现实物在不同问题入口处可以因所论功能不同而选择不同 `topic_body`；但这一步只能在入口完成。进入裁决后，禁止为了说明周边影响而反复改换本体十神。

| 妻 | 财 | 日支为配偶宫 |
| 夫 | 官杀 | 日支为配偶宫 |
| 兄弟姐妹 | 比劫 | 另结合柱位与全局 |

## 6. 与五行、干支和柱位的组合

十神只说明“相对功能”，五行说明“怎样运行”，天干地支说明“以何种形态与场景出现”，柱位和 Topic Lens 说明“落在哪个生活轴”。

例如同为印：

- 木的曲直可让输入偏向培育、框架生长或持续延展；
- 火的炎上可让输入偏向启发、显化、传播或资格被看见；
- 土的稼穑可让输入偏向安顿、承载、消化和长期照料；
- 金的从革可让输入偏向标准、校订、证照与规范；
- 水的润下可让输入偏向渗透学习、信息、储备与恢复。

这些仍只是组合方向，必须继承具体干支与结构状态。

## 7. 正偏边界与课程简化

- 正偏只由阴阳同异确定，不由收入稳定性、职业形式、道德评价或人物亲疏重新命名；
- 若境清课程的“正财＝稳定上班所得、偏财＝生意财”只作入门联想；《千里命稿》明确反对把正财固定为辛苦所得、偏财固定为意外所得；
- 不自动写“正印＝正规学历、偏印＝神秘学”“正官＝好领导、七杀＝坏人”“食神＝温和、伤官＝叛逆”；
- 具体正偏差异须按查询范围回读对应完整原文、命例和当前结构，不以本卡补空白。

## 8. Bridge requirements

要把十神载体写入 finding，至少有：

1. Reader 已核对的十神事实；
2. `kinship_framework` 或其他来源口径已经声明；
3. Topic Lens 已锁定 `topic_body`、`body_relation` 与问题中心；
4. 该十神所在柱、显隐、藏透与关系后状态；
5. `participating_nodes` 与 `action_edges` 已分开，不用周边节点改名本体；
6. 冻结的体—用关系轴说明它是支持、损用、占用、去处还是中性载体；本卡不自行选择结构用神。
7. 若要进入具体职业、岗位、正式身份或事件，另须完成领域轴、位置／可见接口、完整做功路线、日主承载／调用、持续性、去处、现实结果 gate 与竞争载体比较；单一十神功能只能贡献其中一部分。

## 9. 表达校准

- 性质清楚、载体未锁定：`这更像持续输出／庇护承载／规则压力，符合的现实载体包括……`
- 载体有较强锚点：`这里更可能落在学习资质／住房承载／孩子与作品输出。`
- 多个锚点一致：可以直接给出优先判断，不必逐句附加无意义的“但也可能不是”。
- 有竞争轴或状态开关：明确写何时从 A 切到 B，不用“既……又……”糊在一起。

## 11. Cannot decide

本卡不能从一个十神名称直接决定喜忌、结构用神、能力高低、人物好坏、亲属命运、职业、财富、婚姻或具体事件；也不能静默切换六亲流派，或用周边参与节点改写所论之体。
