## 1. Core process

乙继承木的“曲直”，在《千里命稿》的甲乙配对里优先指向**木之形质**：承接木的生气，使其凝结、组织并呈现为枝叶、纹理和具体形态。

本卡以动词描述这一层：**承接、凝成、组织、成形、显现、延展**。柔曲、连接、依托、润饰与精细加工，是乙在不同状态下实现成形的路径或现实载体，不反过来充当乙的固定人格。

乙也不等于花草藤蔓。花草、枝叶、藤蔓、纤维和细长曲线都是木之形质的有效载体；是否落到其中某一种，须看关系后状态、问题中心和现实承载。

## 2. Derivation path

### 八字主要来源路径

```text
木之曲直
→ 甲为木之生气，乙为木之形质
→ 乙承接生气，使其凝成枝叶和可见组织
→ 候选动作：承接、凝成、成形、铺展、细化、连接具体组织
```

“乙为形质”是甲乙内部的相对层级；若以天干／地支为太极点，甲乙仍同属流行之气，寅卯才是时序与地上承载。因此乙只表示更偏向凝成和显形，不能被机械改写成静止实物、只有表面或没有主动性。

所引奇门课程用“阳＝本质、阴＝表象”解释甲乙。本卡只保留它对配对观察的启发，不将它冻结为八字普遍公理，也不把乙定成被动、虚假或只能依附。

## 3. 与甲木的配对差异

| 维度 | 甲的优先观察 | 乙的优先观察 |
|---|---|---|
| 来源定义 | 木之生气 | 木之形质 |
| 过程位置 | 生机发动、流行、推动展开 | 承接生气、凝成、组织并显出形态 |
| 动作候选 | 发端、散布、伸展、领起过程 | 成形、铺展、连接、细化具体组织 |
| 形态候选 | 向上、长直、主干、方长 | 枝叶、柔长、曲线、纹理和细部组织 |
| 常见失衡问题 | 动力无承载、扩展无依、受折或中断 | 形态无支点、组织散乱、牵缠或难以定形 |

“以气而论，甲旺于乙；以质而论，乙坚于甲。”乙的柔曲不等于软弱；形质一旦得到承载，反可坚韧、持续并承担实际作用。没有甲，乙也可能凭自身根气成片成网；“藤萝系甲”只是一种关系状态，不是乙的本体定义。

## 4. Derivation routes

不同取象必须注明来自哪条路线，不把它们堆成同义词表。

### A. 承气成形路线｜优先

- 承接、凝成、组织、显现、完成细部；
- 使生机、想法、关系或资源获得可见结构；
- 现实功能可表现为形成枝叶、纹理、网络、接口或具体成果。

### B. 木形与植物路线｜有效候选

- 生长形态：枝叶、柔长、曲线、铺展、细部繁生；
- 物象载体：花草、藤蔓、禾苗、枝条、纤维、药草；
- 身体形态：修长、纤细、柔韧、曲线感、姿态灵活或细节精致。

这一层需要形质真正获得承载；“乙＝花草＝一定柔弱／漂亮”属于跳步，但花草、藤蔓、柔长和精致本身不是禁词。

### C. 柔曲与连接路线｜成形路径

- 弯转、绕开硬阻、适应空间、维持连续；
- 编织、衔接、形成接口或关系网络；
- 有支点时可借势完成生长，支点失衡时才可能转为牵缠或迁就。

柔性回答“怎样保持形态和连续”，不自动回答命主性格是否软弱或是否依附他人。

### D. 加工与细部路线｜课程候选

雕刻、手工、勾勒、编辑、润色、装饰、设计纹理，可由“形质—细部成形”与课程字形联想共同推出。字形联想单独存在时权重较低。

### E. 身体对应路线｜木类候选

肝、胆、筋、四肢及生长舒展功能属于木类身体对应。乙可进一步指向细部组织、柔韧性和枝末，但须有日主体象、柱位、身体专题和关系后状态复核；不能仅凭一个乙字判断具体疾病。

### F. 行业、人物与场所路线｜现实载体

- 材料型：植物、药草、纤维、纸张、织物、手工制品；
- 功能型：编辑、设计、细化、维护、接口衔接、持续培育；
- 行业例子：园艺、纺织、手工、文字编辑、设计装饰、中医药、教育辅导；
- 人物角色：“辅助人员”只有在十神、柱位与实际分工都支持时才采用，不能从阴木直接绑定；
- 场所型：花园、苗圃、纤维织物环境、曲线与细部装饰明显的空间。

### G. 奇门旁支｜低权重或不迁移

- 润、曲、碧、婉转、柔嫩和得时繁华，可保留为共同形态／状态候选；
- “乙为甲木辅佐”只作该课程角色比喻，不作为八字本体定义；
- 天德之神、卯宫震位、奇门五合四冲、合化、吉凶与具体断验不进入八字 Deep Card；
- 矫揉造作、依附世情等固定道德人格评语不迁移。

## 5. State switches

- **得时、有根、有连续供给**：形质能够持续生长、组织和完成，柔细外形也可形成坚韧承载。
- **有生气但不能凝形**：资源、想法或关系不断进入，却难以组织成具体成果；须由结构判断是缺根、过湿、燥枯还是路线受阻。
- **自身根气足**：乙可独立成片成网，不以见甲作为成立条件。
- **甲确实构成有效支点**：连接和借势可能提高承载；只有关系失衡、支点被占用或交换不对等时，才考虑牵缠、迁就或自主空间不足。
- **适度受制**：可能获得修整、边界、编织或定形；是否适度、是否成器，由 Structure Core 判断。
- **制约或折损过重**：可能成为枝叶受伤、形质萎缩、路线中断或转入隐蔽。
- **过盛而无边界／无去处**：可能枝蔓、细节或接口过多，组织拥挤；不能自动翻成矫揉、虚伪或关系复杂。
- **寒湿、燥枯及火水金土环境**：只作为状态问题；不以单字同现自动定案。
- **被合、被冲、透藏、入墓库或路线占用**：只读取已经审计的关系后状态，本卡不重算边、通量与吉凶。

## 6. Candidate expressions

### 性质与动作

- 承接、凝成、组织、显现、铺展和细化；
- 通过柔曲、连接和调整，使生长在具体空间中保持连续并形成成果；
- 受压时可能转为反复修改、组织松散、枝节过多、牵缠或隐性消耗。

### 外形与身体题

修长、纤细、柔韧、曲线感、细节精致、姿态灵活，以及“细而有韧性”，都是乙木可支持的候选。乙不必然漂亮、瘦弱或缺乏力量。

若身体锚点、得时根气和全盘形态一致，可以明确说“更偏纤细柔长／姿态灵活”或“外柔而有韧性”；有明显土厚、金削、火泄、水漂等改写时，再说明具体怎样改变，不例行制造转折。

### 学习与工作题

- 过程性质：把输入整理成具体成果，完成细部、接口、纹理和可见呈现；
- 工作性质：细化、编辑、协调、连接资源、设计、维护、在限制中找可行路径；
- 载体例子：文字编辑、设计装饰、教育辅导、园艺纺织、手工雕刻、中医药、细部研究；
- 邻接载体：任何行业中的接口、运营、润色、维护、用户体验或流程衔接角色。

必须先确认工作性质，再列例子；“乙木＝花草＝一定园艺／审美行业”不合格。

### 物件与场所题

枝叶、藤蔓、花草、禾苗、绳线、纤维、曲线、细长物、装饰纹样、织物和连接件等都可作为候选。取用哪一个，取决于问题对象、形状、材料、功能及同柱／同路线复核。

## 8. Bridge requirements

每个现实表达记录：

1. `core_process`：调用承气成形、枝叶铺展、柔曲连接还是加工细部路线；
2. `chart_anchor`：由哪个干支、柱位、节点或已冻结路线承载；
3. `post_relation_state`：当前是持续、凝形、受限、牵缠、受损还是尚未显化；
4. `topic_axis`：为什么本题调用外形、身体、学习、职业、关系、人物或物件；
5. `carrier_rank`：candidate／supported／preferred／assertable；
6. `alternative_carriers`：有竞争载体时，为什么其中一个更符合本题。

禁止的是没有桥接便把物象绑定成命主身份；不是禁止提出纤细、漂亮、花草、编辑、设计、辅助岗位或中医药等有效候选。没有真实竞争证据时，也不要为显得谨慎机械制造“但是”。

## 10. Cannot decide

本卡不能单独决定乙是否柔弱、是否依附、是否漂亮、是否为用、是否成化、格局吉凶、疾病、职业、关系模式或唯一现实载体。它也不能以“藤萝系甲”预设甲乙必然形成支点关系。
