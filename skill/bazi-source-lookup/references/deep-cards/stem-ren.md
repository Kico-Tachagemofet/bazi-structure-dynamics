## 1. Core process

壬继承水的“润下”：流动、渗入、汇集、趋向可行的低处，并在通道中搬运、交换和滋养。《滴天髓》所说“壬水通河”“周流不滞”，本卡只取其中的过程义：壬优先表示**开放、连续、跨节点的流通势能**，包括汇集、连接、运输、调度、冲刷，以及沿通道把物质、信息或资源带到别处。

江河海洋、船运物流、交通管网和信息网络，是这一过程可能落成的载体，不是壬的固定身份。壬也不等于“大水”、外向或不停移动；流量、尺度、方向和结果，都要由水源、根气、边界、通道、出口及全局关系共同决定。

## 2. Derivation path

```text
水曰润下
→ 流动、渗入、汇集、趋向可行低处，并沿通道传递
→ 壬优先观察开放、连续、跨节点的流通过程
→ 候选动作：连接、汇流、运输、调度、周转、冲刷、分配、改道
```

《千里命稿》明确批评“壬为江河、癸为雨露”的固定比喻，因此“江河”只能作为壬的高匹配载体。《滴天髓》的“通河”“冲天奔地”也有通根透癸等结构前提，不能抽掉条件变成一见壬便奔腾浩荡的固定结论。

## 3. 与癸水的配对差异

| 维度 | 壬的优先观察 | 癸的优先观察 |
|---|---|---|
| 润下位置 | 开放、连续、跨节点的流通 | 细微、分布式地进入介质与内部层次 |
| 动作候选 | 汇集、连接、运输、调度、周转、冲刷 | 渗透、浸润、凝聚、吸收、潜藏、渐积 |
| 空间感 | 通道、网络、上下游、节点之间 | 缝隙、内部、表层之下、容器之中 |
| 载体候选 | 江河、海洋、船舶、港口、交通、物流和数据网络 | 雨露、水滴、井泉、地下水、地下空间和细密管线 |
| 常见状态问题 | 通道过多而无落点、边界不足、阻塞后改道或溢出 | 无出口的隐性积聚、长期浸泡、细小泄漏或过度内耗 |

这不是大／小、动／静、外向／内向的绝对二分。壬无源时可以只剩细流或流通形式；癸在持续汇集和容器支持下也能形成大水体。两者都必须回到实际状态。

## 4. Derivation routes

### A. 汇流、通河与跨节点连接路线｜优先

- 不同来源进入同一通道，形成连续传递、交换或分配；
- 关注源头、节点、上下游、转运接口、容量、出口与最终落点；
- “通河”优先问能否流通和承载，不直接等于规模巨大或声势浩大。

### B. 运输、周转与调度路线｜过程展开

- 将人员、货物、资金、信息或其他资源从一处送往另一处；
- 可落成物流、交通、贸易、旅行、航运、供应链、通信、平台网络和跨部门调度；
- 这些是工作性质或系统载体，不能从一个壬字直接指定职业。

### C. 冲刷、泄导与改道路线｜条件展开

- 有落差、流量与出口时，可清除沉积、疏通阻力或把压力导向别处；
- 通道受阻时，可能积压、绕行、渗漏或另开路径；
- 水量超过边界与承载时，才可能升级为冲击、泛滥或资源耗散。

### D. 信息、知识与关系网络路线｜现实展开

开放流通可映射为跨来源搜集、跨节点沟通、关系连接、知识联结和信息分发。必须先有学习、工作或关系题的领域锚点；“壬水聪明、善交际”不是无条件的人格结论。

### E. 外形、声音与身体路线｜候选

- 形态感：流动线条、圆转、连续、带水润感或动作转换自然；
- 声音候选：连贯、舒展、音域或气息较开；
- 身体功能候选：肾、泌尿、耳、体液、水液代谢与循环传递。

### F. 物件与场所路线｜现实载体

江河、海洋、湖泊、船舶、港口、码头、管道、泵站、交通线、物流仓配、通信线路、数据网络和跨节点平台均可成为候选，须按流通功能、容量、边界与问题对象复核。

### G. 评注与跨体系旁支｜分层保留

- 《滴天髓》“刚中之德”“有情”等修辞不迁成人格标签；
- “通根透癸，冲天奔地”保留为特定结构状态，不迁成壬的恒常规模；
- 奇门材料中的江河湖海、流动、运输、声音舒展可作共同符号候选；宫位、神煞、吉凶、固定人格和奇门组合断验不迁入八字；
- 课程中的航运、物流、贸易、流动行业可保留为载体，具体职业仍需 Topic 与十神桥接。

## 5. State switches

- **有源、有根、有通道且有出口／落点**：容易形成连续流通、资源周转、跨节点连接和实际输送。
- **失衡而边界不足、方向不清或落点未定**：水势可能到处流动、反复改道，主次与去向难以确定，因而不易收束。多线连接只有在缺少统摄方向或相互牵扯时才成为问题。
- **无出口或受到阻塞**：可能形成停滞、压力、回流、绕行、渗漏或另开路径；不能仅凭“水主流”忽略堵塞状态。
- **水源过量而边界与承载不足**：可能溢出、冲击、冲散既有结构；是否成灾由容量、路线与后续去向决定。
- **土介入**：可成为堤岸、渠道、容器和落点，也可堵塞、吸收或压制；须看土的状态与位置。
- **火介入**：可提供温度、推动循环和显化，也可蒸发、消耗或与水形成对峙；不预设胜负。
- **木介入**：可承接水的输出、疏导与生长用途，也可能增加泄耗；是否有效看木的承载和路线端点。
- **金介入**：可提供源流、器具或管线，也可能使水源过多、偏寒或只生无用；不自动判吉。
- **被合、被冲、透藏、入墓库或路线占用**：只读取 Structure Core 已审计的关系后状态，本卡不重算边、通量、合化或吉凶。

## 6. Candidate expressions

### 性质与动作

连接、汇流、运输、调度、周转、分配、冲刷、疏导和改道。负面状态可表现为流动缺少边界、方向或落点，导致到处游移、主次不清、难以收束；也可由通路相互牵扯、阻塞或容量失配触发。

### 外形与身体题

流动、圆转、连续、水润和动作转换自然可作外形候选；肾、泌尿、耳、体液和循环传递可作身体功能查询。具体外貌、体型和疾病必须有身体锚点及多重证据。

### 学习与工作题

可查询广泛收集、跨来源联结、搭建知识网络、跨部门沟通和让资源通过系统流转的路径。信息来源过多而无整合落点时，才考虑分散或难以沉淀。

### 物件与场所题

江河、海洋、船舶、港口、管线、交通、物流、贸易网络和数据平台均可成为候选，但须按源—路—节点—出口—落点链条复核。

## 8. Bridge requirements

每个现实表达记录：

1. `core_process`：调用汇流连接、运输调度、冲刷泄导、网络传递还是其他路线；
2. `chart_anchor`：由哪个干支、柱位、节点或已冻结路线承载；
3. `post_relation_state`：当前是有源畅通、有路无落点、受阻改道、过量溢出、被吸收还是尚未成流；
4. `topic_axis`：为什么本题调用性格、外形、身体、学习、职业、财富、关系或物件；
5. `carrier_rank`：candidate／supported／preferred／assertable；
6. `alternative_carriers`：江河、物流、贸易、交通、管网、信息网络等竞争载体中，为什么当前一个更符合本题。
