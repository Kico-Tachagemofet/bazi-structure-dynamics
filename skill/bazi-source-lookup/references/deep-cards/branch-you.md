## 1. Core seasonal field

酉是十二月令循环中的**仲秋专气金场**。《千里命稿》列酉属阴金、西方、八月，白露起酉月、寒露前结束，静态只藏辛。相较申的庚壬戊复合发动，酉更接近金气集中、形制完成、表面精整、尺度校准和验收封边的阶段；它不是辛金天干的同义词，也不只等于珠宝或小刀。

酉继承金的“从革”，而专气与仲秋位置使其优先呈现为**精炼、修整、校准、辨别、形成清楚界面并提高完成度**。奇门所说“万物成熟到极致、不能再长”，可理解为生长阶段暂时封口、进入完成与取舍，并非对象必然死亡、永不变化或人生走到终点。

静态藏气集中说明金性接口单一，不代表酉必然清纯、精致、文雅、漂亮或没有刚性。辛在酉中的锋芒可能外露、内藏、用于切削、估值、装饰、交易界面或标准审查；是否形成哪一种表现，仍由对象、位置、关系后状态和现实领域决定。

## 2. Derivation path and fact boundary

```text
金曰从革
→ 仲秋金气集中，材料进入精炼、校准、修整、完成与封边
→ 专气接口由辛承担，庚只出现在月内司令过渡
→ 门户、交易、语言等跨体系候选另设权限
→ 场在／气在／用起／果显分别桥接
```

### 静态藏干、司令、专气与门户必须分开

- `static_hidden_stems`：Reader 当前登记酉只藏辛，辛为本气。
- `commander_sequence`：徐乐吾评注所录酉月司令为庚十日、辛二十日；实际值由 Reader 按白露后偏移与表源登记。
- 庚在酉月前段司令，不等于“酉静态藏庚辛”，也不能据此让庚辛等量同时发用。
- 专气表示静态接口集中，不等于辛已透出、必然得用或现实结果更纯。
- “门户”“交易”“说教／口才”主要来自兑卦、字形与课程联想，只能作为跨体系或载体查询；它们不参与八字关系裁决。

## 3. Seasonal and paired contrasts

| 对照 | 优先观察 | 本卡不允许的简化 |
|---|---|---|
| 申 → 酉 | 申是复合金场、收束发动与开路；酉是专气集中、精细定形与完成验收 | 申大刀、酉小刀就是全部差别 |
| 酉 → 戌 | 酉重金性完成与界面精整；戌把秋金余势、火种和土体带入季秋封存 | 酉一到戌金必入库、锋芒尽失 |
| 酉与辛 | 酉是季节／空间／专气场；辛是其中的人元接口 | 酉＝辛，可套用全部辛金人格职业 |
| 酉与卯 | 仲秋收束定形与仲春生长铺展方向相对，且皆有门户候选 | 未经 Structure 便宣布卯酉冲的搬迁、分手、手术或门坏 |
| 酉与珠宝 | 珠宝是精炼、光泽、价值成形的高匹配载体之一 | 见酉必漂亮、富贵、戴珠宝或从事首饰业 |

酉的“完成”是阶段性状态，不是价值判词。材料可以被精炼成器，也可能因过切、过度修饰、尺度过严、缺少用途或封边太早而失去功能；具体效果必须看加工目标和下游承接。

## 4. Derivation routes and embedded-qi interfaces

### A. 仲秋精炼、校准与完成路线｜优先

修整表面、切削细节、校准尺度、辨别优劣、提高精度、形成接口和进入验收，是酉场的直接机制候选。物件／场所题可以从 `field_layer` 进入金属、镜面、光滑地面、器具、珠饰和精细加工空间，不要求辛先透干。

### B. 辛本气接口｜精细加工、锋芒与价值成形

`YOU-QI-XIN-MAIN` 解释辛在酉中的根气、供给、精细工具、光泽、切削、标准或待时状态。辛为本气不等于漂亮、挑剔、毒舌、珠宝、律师或医生；必须检查加工对象、尺度、用途、权限与现实出口。

### C. 庚—辛司令过渡｜仅限月令查询

`YOU-COMMANDER-GENG-XIN` 解释酉月内部由庚的总体收束向辛的专气精整过渡。庚不进入静态藏干；日数“未可执着”，也不能拿前十日机械断为庚金性格或大刀场景。

### D. 门户、界面与交易路线｜受控候选

奇门笔记把卯酉称作门户之地，课程又以兑卦推出交易。可迁移的共同层是：成品经过清楚界面、出入口、交换标准与价值确认进入他人手中。现实是否为门、柜台、交易平台、审核接口或合同流程，须由题轴、十神功能和场所／职业锚点共同决定。

### E. 珠宝、镜面、小刀与精密器具路线｜现实载体

珠宝、首饰、镜面、光滑表面、小刀、针具、精密器具和细小金属件可回接辛的材料精炼与界面完成。申酉同时出现时，大／小刀对照可以提高相对尺度辨识，但不是绝对规则；酉也可以承载大型精密设备，申也可以承载小工具。

### F. 声音、语言、法律、医学与教学路线｜复合载体

“兑—说”、金属碰撞声和课程口才联想可提供声音、表达、说教、审查、法律、医学与教学线索。它们从单支到具体能力／身份的桥较长：必须另有表达节点、知识／资格功能、权责／医疗轴与现实接口，酉卡只提供 candidate lead。

### G. 鸡鸭鸽鸟、月与小骨路线｜分层候选

鸡是生肖载体，鸭、鸽和会鸣叫的鸟来自课程声音联想；月亮来自“在天为月”的课程象。小块骨骼、牙齿、咽喉／发声与肺系可作身体检索候选，但具体部位、病症和手术必须多锚点复核。

## 5. Manifestation and state switches

| layer | 酉卡可解释什么 | 未通过时仍保留什么 |
|---|---|---|
| `field_layer` | 仲秋、专气金场、精炼、校准、完成、封边、门户／界面环境 | `field-present`；环境／物件题可直接桥接 |
| `qi_layer` | 辛的根气、库存、环境供给、材料、标准或待时状态 | 未透仍保留 stock／root-support／environmental-feed／timing-pending |
| `function_layer` | 辛获 direct-action gate 后的真实加工、审查、切削、交易界面与通量 | 辛起用不等于珠宝、法律、医学或语言身份成立 |
| `result_layer` | 成器、估值、交换、封边、过切或损伤是否进入现实领域 | 未接通时只写场、库存、机制或候选 |

- **材料、尺度、工具和用途匹配**：可精炼、校准、修饰、验收并提高完成度／单位价值。
- **裁切或标准过度**：才考虑过分挑剔、细节伤损、封边太早和形式压过功能；精细本身不是负面。
- **材料不足或用途不明**：可能只有标准意识、表面修整或待时器具，不可因此断“有形式无实质”。
- **门户／交易接口成立**：可把成品送入交换、审核或展示；没有关系轴和现实平台时只保留界面候选。
- **timing／synastry 激活**：只重算辛或外来庚的实际节点、作用边、覆盖范围和 expiry，不回写原局。

## 6. Candidate expressions

### 性质与动作

精炼、切削、校准、辨别、修整、估值、验收、封边与建立交换界面。人物锚点稳定成立时，可查询重视精度、能发现细节、修正偏差和提高完成度；标准与对象失配时才查询过度挑剔、修饰过头或过早封口，不得固定成文雅、安静、漂亮、毒舌或完美主义。

### 形态、身体与环境

光泽、镜面、光滑、精细、清楚边缘、珠饰和小型器具可作形态候选。小骨、牙齿、肺、咽喉与发声只作身体检索入口，不从酉支直接诊断疾病。

### 学习、工作与资源

可查询校订、审核、精加工、质量检查、估值、界面设计、谈判交换和语言表达等性质。珠宝、法律、医学、教师、交易、精密制造等具体工作须另走领域载体比较。

### 物件、场所与动物

珠宝首饰、镜子、光滑路面／停车场、小刀针具、精密器件、门与交换界面、鸡鸭鸽鸟和月亮可作候选；选择哪个取决于功能、材料、位置和题目。
