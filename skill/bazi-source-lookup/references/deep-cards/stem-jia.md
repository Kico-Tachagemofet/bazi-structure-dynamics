## 1. Core process

甲继承木的“曲直”，在《千里命稿》的甲乙配对里优先指向**木之生气**：生机初发、流行散布，并推动生长过程开始展开。

本卡以动词描述这一层：**发端、萌动、流行、散布、推动、伸展**。建立主轴、撑起结构、形成栋梁可以是甲气落实后的功能，但不反过来充当甲的唯一核心。

甲也不等于大树。大树、树干、栋梁、长杆、高挑挺拔都是木气以长直形态显现时的有效候选；是否落到其中某一种，须再看关系后状态、问题中心和现实承载。

## 2. Derivation path

### 八字主要来源路径

```text
木之曲直
→ 甲为木之生气，乙为木之形质
→ 甲侧重使生长开始、流行并向外展开
→ 候选动作：发起、萌生、推动、伸展、领起一个过程
```

《千里命稿》先批评“甲固定等于栋梁、乙固定等于萝藤”一类失伦比喻，再用气／质解释甲乙。徐乐吾评注的“阳和初转，其势方张”可帮助展开甲的发动性，但仍属于评注层，不倒署为原书原句。

“阳＝本质、阴＝表象”是所引奇门课程的解释框架，本卡不把它冻结为八字普遍公理；甲乙在本卡中的优先区别，以八字来源明确提出的生气／形质为准。

## 3. 与乙木的配对差异

| 维度 | 甲的优先观察 | 乙的优先观察 |
|---|---|---|
| 来源定义 | 木之生气 | 木之形质 |
| 过程位置 | 生机发动、流行、推动展开 | 承接生气、凝成并显出具体形态 |
| 动作候选 | 发端、散布、伸展、领起过程 | 连接、延展、成形、调整具体组织 |
| 形态候选 | 向上、长直、主干、方长 | 枝叶、柔长、曲线、细部组织 |
| 常见失衡问题 | 动力无承载、扩展无依、受折或中断 | 形态无支点、缠绕散漫、依附过度或难以定形 |

配对差异是观察入口，不是见甲必直、见乙必曲，也不把“气”自动等同于强、“质”自动等同于弱。甲乙在具体命局中的承载与作用，完全继承 Structure Core 的裁决。

## 4. Derivation routes

不同取象必须注明来自哪条路线，不把它们堆成同义词表。

### A. 生气与过程路线｜优先

- 启动、萌发、推动、开端、向外展开；
- 使一个计划、关系、组织或生命过程开始生长；
- 现实功能可表现为发起、培育、带动和持续扩展。

### B. 木形与材料路线｜有效候选

- 生长方向：向上、伸展、长直、挺拔；
- 成形物象：树木、树干、栋梁、梁柱、长杆、骨架；
- 身体形态：高挑、修长、骨架舒展、方长感。

这一层需要木气真正获得形体承载；“甲＝大树＝一定高大”属于跳步，但“大树、高挑、栋梁”本身不是禁词。

### C. 序位路线｜课程候选

甲为十干之首，可延伸为开始、第一、领头、首部或主项。它回答的是次序与职责，不直接证明命主有领导品德、一定当领导或凡事居首。

### D. 身体对应路线｜木类候选

肝、胆、筋、四肢及生长舒展功能属于木类身体对应。要进一步落到甲，仍须有日主体象、柱位、十神关系、身体专题和关系后状态的复核；不能仅凭一个甲字判断具体疾病。

### E. 材料、物件与场所路线｜符号载体

- 材料型：植物、木材、纤维、纸张、书籍；
- 场所型：林木环境、长形通道、梁柱或骨架明显的空间。

培育、发起、研发、建立主线和推动长期成长属于甲可贡献的**工作性质**，不是职业、岗位或身份。教育、组织建设、领导、项目负责人等属于 `composite_domain_carrier`，不由本卡直接提出或升格，须在领域载体层结合十神功能、柱位、完整路线、日主承载、现实结果 gate 和竞争载体裁定。

### F. 字形与奇门旁支｜低权重或不迁移

- 甲壳、方形面部等字形联想，只作低权重课程候选；
- 奇门材料中的雷、震位、天福之神、宫位、起局和断验不进入八字 Deep Card；
- 奇门所说“质劲、体方长、得时栋梁”等，只保留能回接木形与状态的共同符号层，不覆盖八字气／质核心。

## 5. State switches

- **得时、有根、有连续供给**：生气较容易持续发动，并凝成可见的生长、主线或承载功能。
- **有生机但缺根／缺载体**：可能不断发起和伸展，却难以落定；课程中的“漂泊无依”只在这一状态得到结构支持时才作候选。
- **供给过多而无边界／无去处**：可能扩展过快、枝路过多或只见发动而不见完成，不能直接翻成自负或失败。
- **适度受制**：可能获得修整、边界和成材条件；是否适度、是否真正成材，由 Structure Core 判断。
- **制约或折损过重**：可能表现为生机受抑、路线中断、形质受伤、转入防守或只保留局部功能。
- **火、水、土、金改变环境**：可分别追问耗泄与显化、滋养与漂浮、扎根与壅滞、修整与损伤；不以单字同现自动定案。
- **被合、被冲、透藏、入墓库或路线占用**：只读取已经审计的关系后状态，本卡不重算边、通量与吉凶。

## 6. Candidate expressions

### 性质与动作

- 发起、萌生、推动、带动、向外展开；
- 使资源进入生长过程，逐步形成主线、枝干或长期结构；
- 受压时可能转为硬撑、反复重启、扩展无依或局部保留。

### 外形与身体题

高挑、修长、挺拔、骨架舒展、长形或方长感，都是甲木可真实支持的候选。

进入命主外形结论前，至少检查：

1. 甲是否与日主、身体题或外形承载直接相关；
2. 木气是否得令、得根、可见并获得形体承载；
3. 土厚、金削、水漂、火泄等竞争形态是否改变结果；
4. 同柱、全盘形态与现实性别／年龄条件是否共同支持。

证据一致时可以直接写“外形更可能高挑挺拔”，不强制补一个空泛的“但不一定”。

### 学习与工作题

- 过程性质：启动学习、搭起第一层框架、长期培育、推动项目成长；
- 工作性质：发起、培养、研发、建立主线、承担骨干或持续扩展；
- 直接符号载体：植物、木材、纤维、纸张等材料，以及长形／主干式物件与环境；
- 复合载体提示：教育、规划、组织建设、项目负责人、团队骨干等不得从甲单独进入 finding，只能由领域载体层在完整结构桥接后提出。

行业表达先说明工作性质，再由领域载体层列符合条件的行业、岗位或工作内容。甲只为已经成立的载体提供生发、领起、伸展或主干式着色。

### 物件与场所题

树木、树干、梁柱、长杆、骨架、道路主轴、书籍纸张等都可作为候选。取用哪一个，取决于问题对象、形状、材料、功能及同柱／同路线复核。

## 8. Bridge requirements

每个现实表达记录：

1. `core_process`：调用生气发动、木形伸展、序位领起还是其他路线；
2. `chart_anchor`：由哪个干支、柱位、节点或已冻结路线承载；
3. `post_relation_state`：当前是持续、受限、改道、成形、受损还是尚未显化；
4. `topic_axis`：为什么本题调用外形、身体、学习、职业、人物或物件；
5. `carrier_rank`：candidate／supported／preferred／assertable；
6. `alternative_carriers`：有竞争载体时，为什么其中一个更符合本题。

禁止的是没有桥接便把物象绑定成命主身份。高大、栋梁、树木、木材等仍可作为甲的形态／材料候选；领导、教育等则不是甲卡自身候选，只能由复合领域载体层在相关结构成立后激活。没有真实竞争证据时，也不要为显得谨慎机械制造“但是”。

## 12. Forward-test questions

1. 模型能否先解释甲的生气发动，并把领导、教育留给复合领域载体层，而不是从甲卡直接提出？
2. 模型能否把甲乙理解为同一木过程的气／形两层，而不是两种固定植物或两类固定人格？
3. 外形锚点充分时，模型能否明确说高挑挺拔，而不机械加空洞转折？
4. 甲受制时，模型是否会回读结构状态，区分修整成材、功能抑制和形质损伤？
5. 模型是否会误把奇门震位、天福之神或课程字形联想带入八字结构裁决？
6. 性格、学习、财富与家庭题中，模型能否先锁定人物／领域体，再调用甲的发动过程，而不是把甲直接写成固定人格、富贵标签或六亲身份？
7. 杀印相生等权责路线成立时，模型能否先由领域层比较领导、专业权威、机构／资格岗位，再让甲只负责领起／主干式着色？
