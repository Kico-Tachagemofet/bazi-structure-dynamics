# 八字 Deep Card 使用与编写规范（v0.4）

Deep Card 是**取象素材库**，不是结构裁决表，也不是免责声明集。它帮助下游把已经确立的旺衰、格局、十神链和干支关系，转化成鲜活、贴近现实且有跨盘区分度的生活画面与职业／人事载体。

## 1. 核心推导

```text
五行本性 × 阴阳差异 × 原局旺衰/燥湿/关系后状态 × 相对日主的十神功能 × 柱位人事范围
= 动作与质地 → 现实载体家族（含传统与现代、跨阶层候选） → 层级、结果、代价与转折
```

单张卡只提供符号本象、状态切换和候选载体；具体格局高低、职业方向、六亲状态和事件，必须由多节点组合与完整作用链决定。

## 2. 一张精简卡（v0.4）只保留五块高价值内容

每张单干／单支卡控制在约 50–80 行，避免大段重复禁令与抽象管理学黑话：

1. **核心本象与阴阳／季节对照**：这个符号在《尚书·洪范》《千里命稿》《子平真诠评注／滴天髓》里的核心动势，以及与同组配对项（如甲/乙、丙/丁、辰/戌/丑/未）的关键差异。
2. **地支藏干与司令边界**（仅地支卡）：标明 Reader 静态藏干与月令司令时序分开、四层显化（`场在 / 气在 / 用起 / 果显`）分开，冲合不自动开库或全气齐发。
3. **状态开关（得势 vs 失衡）**：在得令有根、燥湿寒暖变化、受生受制或路线畅阻时，现实质地怎样明显分化（写出具体反差，而非只用“好版本/坏版本”敷衍）。
4. **跨领域鲜活载体**：按**性情与处事、外形与身体（传统象义）、行业与职业（覆盖体制、技术、手艺、经商、实业、文化、服务等跨阶层场景）、场所与器物**分类列举；不把所有符号都压成互联网白领或项目管理词汇。
5. **一句话边界与来源署名**：简明注明本卡不越权裁决结构，以及原文／评注／课程／跨体系材料的来源分层。

## 3. 在 Fresh Reading Pipeline 中的调用方式

- **Source Lookup（Reading-pack 模式）**：范围确认后，只选取本盘实际出现并参与结构的五行、十神、天干、地支、关键藏干及大运流年卡片，写入 `source-notes.md` 的候选摘录，并将对应卡复制到 `reading-pack/materials/`。
- **Fresh Reader-Writer（`$bazi-render`）**：在干净上下文中完整读取 `reading-pack/` 内的结构笔记与相关卡片，直接完成十神—干支综合取象、载体排序与断盘成文。
- **可选诊断工具（`$bazi-imagery-composition`）**：仅在用户要求查看推导底稿或补齐特定专题缺口时调用，不属于常规必经阶段。

## 4. 写作避坑

- **敢于定主次**：多锚点一致时直接给优先判断和层级排序，不要因为存在替代载体就退回泛泛性格描述或 50/50 骑墙。
- **破除单一白领视角**：避免用“复杂材料、流程切换、收口、兜底、可复用方案、交付”等万能词覆盖全部五行与地支。
- **保真来源分层**：《千里命稿》批评的固定单物象（如“甲必栋梁、壬必江河”）只作高匹配载体而非唯一定义；课程取象与跨体系共同象征不冒充原典定论。
