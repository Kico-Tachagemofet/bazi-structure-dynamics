# 读者覆盖与判断维度剖面 v3

本文件定义“一个完整专题不能漏查哪些人事面，并且哪些现实端点必须得到方向判断”。它不是用户问题、结论模板、十神模板或 Render 目录。

## 使用原则

1. 先按求测者的问题和 scope 选择剖面，再用冻结命盘裁定。不得从盘中某个醒目十神倒推读者必须问什么。
2. 每个必查 facet 必须唯一处置为 `primary`、`supporting`、`cross-ref`、`not-applicable` 或 `source-gap`。“本盘不成独立过程”是合格结果，静默漏查不是。
3. 常规十神、柱位与六亲只是候选检索器。须经关系后状态、实际控制者、去处和竞争路线裁定；不得因为“十神都要讲”便给每颗十神建一条 finding。
4. scene kernel 对应一个可分辨的现实因果场景，不与 facet、axis 或 finding 一一对应。同一 process 可以提供共同事实脊柱，但不同结果端点、specificity level、去处、载体或岁运 switch 必须先形成独立 claim kernel；只能在 Composition 散文中合写，不能在 finding 前消失。
5. 每个 primary axis 的上游材料至少要能支持六种解释职责：`formation`、`advantage`、`cost`、`result-gate`、`switch`、`verification`。不适用的职责须说明理由。这些是 Composition 的内容角色，不得机械变成问题、小标题或固定段落。
6. facet slug 只作稳定 coverage 索引。不得把它改写成 `exact_reader_question`；只有用户真正问出的专项问题才进入 `explicit_reader_questions` 与 Reader Answer Contract。
7. `coverage-receipt.json` 最终证明 facet 已进入 scene kernel、finding 与正文 span。真实问题另沿 question-answer map 闭合；两种收据不得互相替代。
8. supporting／cross-ref 可以共享因果场景，但必须写明本领域新增的对象、载体、结果或条件差异。只复用 process ID 或总括句不算覆盖。

## 基础与常用剖面

### family-home

- `family-resources-and-maintenance`：家庭资源、支出与日常维持。
- `family-duty-and-authority`：规则、责任、权威与谁收尾。
- `care-support-and-method`：照顾、信息、方法与实际帮助是否到位。
- `family-boundary-and-sharing`：共同承担、手足／同住者、资源共享与边界。
- `living-environment-and-stability`：居住、生活秩序与变动条件。

### education-learning

- `learning-input-and-method`：资料、师承、理解方法与资格基础。
- `comprehension-and-integration`：是否能将输入变成自己的知识结构。
- `expression-and-assessment`：作答、写作、论文、作品与考核门槛。
- `qualification-and-path`：学历、证书、专业路径与正式认可。
- `peer-competition-and-sharing`：同学、合作、比较与资料共享。
- `learning-sustainability-and-conversion`：能否长期累积，以及如何转成实际成果。

必须另登记并最终裁决：`education-attainment-level`、`formal-credential-likelihood`、`professional-training-depth`、`study-work-coexistence`、`formative-luck-realization`。只写“学习能力／学习方法”不构成本专题闭合。

### wealth-resource

- `income-interface`：资源、项目、客户或工资从哪条路进入。
- `production-and-monetization`：产品、服务、表达、技术或交易如何生财。
- `gross-result-and-obligation`：收入、可见成果与合同／交付／风险成本。
- `retention-liquidity-and-protection`：能否留存、周转、定价与建立保护层。
- `sharing-competition-and-allocation`：合作分配、共同投入与竞争。
- `wealth-sustainability-and-reversal`：资源增长在什么条件下成为净收益，何时转成负担。

必须另登记并最终裁决：`earning-capacity`、`primary-income-channel`、`gross-versus-net`、`retention-and-assetization`、`allocation-leakage`、`timing-realization-mode`。

### career-work

- `task-and-problem-type`：实际处理什么任务、难题和容错要求。
- `organization-duty-and-authority`：上司、制度、责任、权限与位职。
- `method-qualification-and-support`：专业方法、资质、授权、信息与组织依托。
- `output-solution-and-innovation`：方案、表达、解题、创新与规则协商。
- `recognition-result-and-responsibility`：成果、赏识、可见度是否同时转成授权，还是只增加责任。
- `income-and-net-return`：工资／项目回报、交付义务与净收益分开。
- `peer-collaboration-and-competition`：同事、同级、合作方、竞争与共享资源。
- `role-growth-and-sustainability`：专业权威、管理／项目角色、发展与长期负荷。

必须另登记并最终裁决：`occupational-nature`、`core-action-and-material`、`institution-qualification-authority`、`professional-reputation`、`income-realization`、`unit-role-mobility`、`conflict-and-cost`。只写工作流程、责任感或性格不构成本专题闭合。

### love-relationship

- `attraction-and-selection`：吸引、选择与主动／被动节奏。
- `commitment-duty-and-power`：承诺、规则、责任与主导关系。
- `communication-and-boundary`：表达、协商、自主性与边界。
- `care-safety-and-understanding`：安全感、支持与理解是否可用。
- `resource-and-role-allocation`：投入、时间、金钱与角色分工。
- `stability-conflict-and-reversal`：关系何时可承载，何时转成压迫或失衡。

必须另登记并最终裁决：`relationship-entry-and-selection`、`partner-role-carrier`、`commitment-and-stability`、`resource-duty-allocation`、`conflict-and-separation-risk`、`repair-or-reversal-condition`。

### health-body

- `load-source`：负荷从哪条五行过程而来。
- `recovery-and-support`：补给、休整、节律与现实支持。
- `output-and-depletion`：输出、事务、紧张与身体成本。
- `rhythm-and-sustainability`：启动、持续、恢复与停止节奏。
- `trigger-rebound-and-observation`：加重／缓解条件、反复方式与可观察面；不作疾病诊断。

### occult-perception

- `reception-and-pattern-recognition`：信息接收、联想与模式识别的内部潜能。
- `lineage-learning-and-method`：经典、师承、非标准学习与方法稳定性。
- `interpretation-and-integration`：如何把接收的材料变成可说明的理解。
- `discernment-boundary-and-verification`：来源、边界、反证与核验方法。
- `reading-writing-and-teaching`：解读、写作、教学或把感受转成可检验命题。
- `public-client-and-exchange`：公开输出、客户、收费与责任成本。
- `practice-sustainability-and-boundary`：长期学习、辨识质量、输出频率与负荷上限。

### creation-expression

- `material-input-and-incubation`：素材、知识、观察与酿造。
- `generation-and-technique`：创意启动、方法与技术。
- `expression-and-finished-output`：作品、表达与收口。
- `evaluation-visibility-and-rules`：平台、标准、评价与被看见。
- `monetization-and-obligation`：商业化、交付、收入与更新压力。
- `creative-sustainability-and-reversal`：持续创作的补给、负荷与反转条件。

### social-collaboration

- `relation-field-and-role`：群体、同伴、合作者与角色位置。
- `communication-and-coordination`：表达、协调与冲突处理。
- `peer-support-and-competition`：同侬支持、比较、竞争与分配。
- `resource-rule-and-boundary`：共享资源、规则、决策权与边界。
- `long-term-collaboration-and-exit`：长期合作、维护成本与退出条件。

## 岁运剖面

每个大运或流年 atom 都至少检查：

- `overlay-structural-delta`：外来干支新增、加强、合绊、克制或改道了什么。
- `retained-natal-baseline`：哪些原局关系和主路仍然成立，剩余通量如何。
- `activated-function-transition`：哪个原局 latent／timing-only 功能因本窗口获得临时资格，只做根气、直接功能还是可见接口。
- `domain-manifestation-candidates`：在当前题目中可能落成哪些人物、岗位、制度、资源或事件场景。
- `impact-and-resilience`：受影响 process 的核心度、原局剩余主路、备用路线、运层持续时间与现实承接共同决定影响带。
- `agency-position-and-uncontrolled-result`：命主当时职位／角色会改变现实载体和可控范围，但不改写结构 diff；未知时保留条件分支。
- `expiry-and-next-window`：覆盖层到期撤销什么，哪些只回到原局基线。

不得写死“原局一定压过流年”或“流年一来便覆盖原局”。原局给出基线架构，大运／流年／流月给出不同层级和持续时间的临时变量；影响轻重必须经重算后裁定。
