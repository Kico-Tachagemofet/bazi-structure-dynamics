只把已证明有力的结构翻译为性格、能力、职业或关系表现；每项注明来自哪条作用链，并链接相应完整取象卡。压缩索引不能单独承担取象证据。若资料库尚无展开版本，明确说明缺口，不自行补写。避免宿命化和确定性事件预言。

## 审计清单

- [ ] 是否从月令而不是醒目天干立格？
- [ ] 是否按柱位逐一分析四个天干及全部藏干，而非先聚合？
- [ ] 是否把身强身弱放在证据汇总之后？
- [ ] 是否同时画出制、化、生、泄的竞争路线？
- [ ] 是否考虑位置远近与透藏差异？
- [ ] 是否区分合绊与合化？
- [ ] 是否把地支冲合落实到格神、用神或忌神？
- [ ] 是否把财制枭、财生杀、枭夺食等双重功能同时保留？
- [ ] 是否把“作用链已显化”和“该十神是全局用神”分开？
- [ ] 用户给出经历时，是否先区分显化映射与预注册验证，并避免强行改派象义？
- [ ] 是否给出至少一个反证和改变条件？
- [ ] 是否隔离其他简化体系和个人背景？
- [ ] 涉及取象时，是否读取了完整展开材料，而非只依赖摘要或一句口诀？

任一关键项缺失时，不给“唯一格局”“唯一用神”或确定性吉凶结论。
