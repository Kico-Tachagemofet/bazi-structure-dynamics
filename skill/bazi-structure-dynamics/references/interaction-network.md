## 1. 有向网络

把每条关系写成：

> 来源节点 → 目标节点｜机制｜距离｜双方力量｜实际结果｜阻断条件

区分五种结果：增力、减力、转流、羁绊、引动。不要只写“有某某组合”。

## 2. 天干作用

- 紧贴天干作用最直接；隔一柱降低，年时遥隔通常只保留全局五行影响。
- 距离是先验权重，不是一票否决。若已发生的重复事实准确对应某条隔柱作用，应上调该链在相应生活领域的显化置信度，同时保留其直接力弱于紧贴关系的结构判断。
- 同柱干支有直接坐根、截脚、盖头关系，但仍须看藏干层级与季节。
- 克与合并见时，先看紧贴，再看强弱、得令、数量和通关。
- 两干争合一干时，记录妒合及各自力量；不因出现五合就自动“合走”。
- 合化必须另证：得令、化神有势、位置与明暗允许、原五行是否仍有根援。证据不足只判合绊。

## 3. 藏干与地支

- 藏干可以生克透干，也可以作为透干根源；其力度由本中余气、月令、数量、同党、位置和引动共同决定。
- “藏而不透”表示潜伏和间接，不表示零作用。
- 地支不能只看表面五行，也不能只看藏干；先看支的整体关系，再看内部藏干怎样被引动。
- 月支和日支通常比远支更直接，但不得用宫位代替力量判断。

## 4. 合冲刑害

一般结构强度可参考：方合、完整三合、六冲、六合、刑害；实际顺序可被月令、数量、紧贴和根气反转。

- 方合/三合：把多支力量集中到某五行；成局后再判断该五行是药还是病。
- 半合：带旺支者较实；缺旺支的拱合只列候选，不当完整合局。
- 六合：以羁绊、聚合、改变去路为先，不自动判吉或化。
- 六冲：比较双方本气、季节、数量与根；冲用可能坏，冲忌可能解。
- 辰戌丑未冲：重点检查土被激发、库气开合及藏干冲突，不简单判“土散”。
- 刑：优先理解为动摇、摩擦和内部不协调，力度通常低于强冲合。
- 害/破：作为关系受损和暗中妨碍的次级证据，不单独定性。

## 5. 竞争路径

完整原局至少搜索以下结构：

```text
食神 ─克→ 七杀
食神 ─生→ 财 ─生→ 七杀

七杀 ─克→ 日主
七杀 ─生→ 印 ─生→ 日主

偏印 ─克→ 食神
偏财 ─克→ 偏印
偏财 ─生→ 七杀
```

这些关系不是互相取消，而是争夺同一股力量的去路。判断主导路径时比较：

1. 谁得令、得根和透出。
2. 哪些节点紧贴或同柱。
3. 中间节点是否真的能承接。
4. 日主是否承担得起该路线的代价。
5. 是否有另一条旁路把“药”重新导回“病”。

## 6. 引动

把结论分为：

- 原局成立：四柱内条件已齐。
- 原局潜伏：有根或藏干，但显性、距离或力量不足。
- 岁运可引：等待透出、补齐三合方会、冲开、合入或扶强某节点。
- 岁运反转：原本的药被合冲、原本的病得根，导致主导路径变化。

原局潜伏项须把“潜在开关”写成 activation interface：当前参与层、可匹配的 trigger signature、命中后从哪一阶段重算、受影响的支局／节点／边／路线条件与最强反证。没有岁运问题时，只登记接口，不擅自展开具体年份吉凶。

岁运或合盘进入时按以下顺序：

1. 在冻结 natal 之外建立临时节点；
2. 匹配 activation interface；
3. 只把匹配项标为 `matched-pending-requalification`；
4. 从登记的最早受影响阶段重裁支局、节点、竞争分配与作用边；
5. 输出 before／after diff、持续方式与失效条件；
6. 覆盖期结束撤销临时差分，原局状态不变。

另一人的干支只有在双方 natal 分别审计、跨盘关系成立且本题调用该关系场时，才能充当 relationship-bound 临时节点。对方有同字／同五行本身不构成激活证据。

## 7. 经历映射与验证

读取经历后先区分显化映射与证据验证。显化映射可以把对应关系拆开：

- 作用链命中：哪条生克制化最直接解释事件机制。
- 领域命中：事件落在学习、职业、关系、财务或健康的哪一轴。
- 时间命中：是否需要岁运资料才能解释发生时间；没有岁运时不补写年份原因。
- 净效果：事件结果是建设性、破坏性还是先曲后成。

允许一个事件由多条链共同说明，但指出各自职责。优先采用更直接、信息损失更少的解释，不为维护原结论把已命中的象强行转交给较迂回的结构。

上述对应本身不增加结构置信度。若要称为验证，必须在读取相关经历前按 `validation-protocol.md` 预注册并冻结时间窗、顺序、路线机制、领域竞争和失败条件，再依据原始回应固定计分；不得把事后找到的最直观对应冒充盲验证。
