## 1. 月令取格

普通八格为正财、偏财、正官、七杀、正印、偏印、食神、伤官。

依次检查：

1. 月支本气或当令司令是否透干；透出者优先。
2. 本气不透时，月支其他藏干是否透出，力量是否足，是否受严重克合。
3. 都不透时，比较月支藏干的实际力量，谨慎选取格局候选。
4. 月令为日主禄刃时，另查建禄、月刃等外格。

“七杀在年干”只是位置事实；只有它来自月令、或另有严格外格依据，才可称七杀格。月令七杀透到年干时，可写“月令之杀透年”。

## 2. 五种角色

| 角色 | 定义 |
|---|---|
| 格神 | 由月令确立的结构中心 |
| 功能用神 | 成格、救败、抑太过、扶不及或通关的关键节点 |
| 相神 | 保护、支持或使功能用神可持续工作的节点 |
| 喜神 | 实际帮助格局、用神或流通者 |
| 忌神 | 实际破格、伤用或加重病处者 |

古籍有时把月令所取的格神称为“用神”。遇到这种材料时注明“古典格局用神”，不要与现代“补救用神”混写。

## 3. 成败太过不及

- 成：格神有力，日主能承，且生扶、制化或流通配合得当。
- 败：格神或关键救应被破，矛盾无解。
- 太过：格神或制化力量过盛，超出日主或对手承载。
- 不及：格神或救应太弱、无根、被泄克，无法完成任务。

先找到病，再指定药。不要因为某十神传统上“吉”就指定为用神。

## 4. 常见功能路线

| 路线 | 成立条件 | 常见反转 |
|---|---|---|
| 食神制杀 | 杀有压力，食神有力，日主承担得起泄身 | 食弱杀重则制不住；食重杀轻则制杀太过；财可泄食生杀 |
| 杀印相生 | 杀旺身弱，印能承杀并生身 | 财坏印、印无根或杀不流向印时失败 |
| 身强任杀 | 日主有力，杀清而适度 | 杀太轻无权；杀重无制化则攻身 |
| 财生官杀 | 身强、官杀不足时可成权责 | 身弱杀旺时财党杀、耗身 |
| 食伤生财 | 身强且财有承接 | 身弱时连续泄耗；财再生杀可能回流为病 |
| 偏财制枭 | 财、枭均有实际力量；可把偏印的冷门知识、吸收与非标准路线导向现实用途和市场价值 | 日主弱、需枭生身化杀时，财仍会损救应；同时检查财耗身与财生杀 |
| 正财坏印 | 正印过旺且身强时可调平 | 身弱赖印时为破坏 |
| 印制食伤 | 身弱、食伤过旺时护身 | 食神承担制杀或生财任务时可能夺食破路 |

同一节点可以处在多条路线中。必须画出全部主要路线，再比较净效果。

## 5. 七杀结构检查

依次回答：

1. 七杀是不是月令格神，还是局中重要十神？
2. 七杀得令、得根、透出和来源如何？财是否紧邻生杀？
3. 日主是身强、身杀两停，还是杀重身轻？
4. 食神制杀是否会进一步泄弱日主？食神是否透、得根、受枭夺或被财泄？
5. 印能否把“杀克身”改写为“杀生印、印生身”？印是否遭财破坏？
6. 制杀与化杀能否并行，还是互相伤害？

经验性优先级：身杀两停可优先看制；杀重身轻优先看化与扶；身强杀浅需防制杀太过。最终仍以全局力量为准。

## 6. 偏印与财的检查

《千里命稿》细分为“偏财制枭”和“正财坏印”。广义都属于财克印，但功能不同。

判断偏财制枭是否有利时，至少检查：

- 偏印是在生身、化杀、御伤，还是在夺食、生身太过？
- 日主是否承受得起财耗？
- 财是否同时生旺官杀？
- 财与偏印是否紧贴，还是隔柱遥克？
- 偏印被制后，食神能否真正完成制杀或生财任务？

必须分成四层下结论：

1. **关系层**：财克偏印是否存在。
2. **力量层**：财与偏印是否都足以使关系起效。
3. **领域层**：它在学习、职业、证书、财务或其他领域怎样显化。
4. **全局层**：它对日主承载力和其他格局路线的净效果。

财制枭在学习与职业轴上的常见表达包括：把抽象或冷门知识变成可就业、可收费、可交付的技术；抑制只学不用；求学路径转折、换专业、换岗位或经职业证书重新定向。出现这些事实时，可判该链已经显化，不得因为财不是全局首选用神就否认它。

象义仍需以结构和事实共同校准：受适度约束且有用的偏印，可表现为非标准知识、专门技术、冷门研究或独立认知；枭旺为病时也可表现为封闭、偏执、只吸收不输出。财制枭可以改善后者，同时保留财耗身、生杀或伤及化杀印的代价。
