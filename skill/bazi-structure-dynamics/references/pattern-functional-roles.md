## 1. 月令取格

普通八格为正财、偏财、正官、七杀、正印、偏印、食神、伤官。

依次检查：

1. 月支本气或当令司令是否透干；透出者优先。
2. 本气不透时，月支其他藏干是否透出，力量是否足，是否受严重克合。
3. 都不透时，比较月支藏干的实际力量，谨慎选取格局候选。
4. 月令为日主禄刃时，另查建禄、月刃等外格；唯普通扶抑彻底失效且满足严苛条件时，方议从格、专旺或化气外格（兼顾《滴天髓》“五阳从气不从势，五阴从势无情义”之别）。

“某十神在年干／时干”只是位置事实；只有它来自月令（透干或会支）、或另有严格外格依据，才可据此立格。

## 2. 五种角色

| 角色 | 定义 |
|---|---|
| 格神 | 由月令确立的结构中心 |
| 功能用神 | 成格、救败、抑太过、扶不及或通关调候的关键节点 |
| 相神 | 保护、支持或使格局／功能用神可持续工作的关键节点 |
| 喜神 | 实际帮助格局、用神或流通者 |
| 忌神 | 实际破格、伤用或加重病处者 |

古籍（尤其《子平真诠》原文）常把月令所取的格神称为“用神”。行文或引用时必须区分“古典月令用神（格神）”与“现代功能补救用神”，不混为一谈。

## 3. 成败清浊与太过不及

- **成**：格神有力，日主能承，且生扶、制化、调候或流通配合得当。
- **败**：格神或关键相神被破，核心病灶无解。
- **清与浊**：用神专一、去留分明、干支有情为清；财官印食杂出互碍、官杀混杂无清、药被病占为浊（成中带忌）。格局清浊直接影响现实层级与顺逆质地。
- **太过／不及**：格神或救应过盛超出承载为太过；根轻、受燥湿压制、无通关或被克泄为不及。

先找真病，再定真药，并核实这味药在原局“是通畅可用，还是受阻待运”。不要因某十神传统称“吉神”就盲目定用。

## 4. 常见功能路线

| 路线 | 成立条件 | 常见反转 |
|---|---|---|
| 财旺生官／官印相生 | 身强喜财生官，身弱或遇伤官喜印护官 | 身弱财官两旺反成重压；印格逢财破印；伤官见官无救 |
| 食伤生财 | 日主能承泄耗，且财有根气与承接 | 身弱连续泄耗；财再生杀回流攻身；比劫无制直接夺财 |
| 食神制杀 | 杀旺有压力，食神有力，且**身健能承泄**（阳干尤须身健） | 身弱则克泄交加；食重杀轻则制杀太过；透财泄食生杀；印露夺食护杀 |
| 杀印相生 | 杀旺身弱，印有根润且能承杀生身 | 财坏印、燥土脆印、土厚埋金、或印无根难传力 |
| 伤官佩印／伤官生财 | 伤旺身弱喜印制伤生身（尤利夏木调候）；身强喜伤生财 | 伤轻身旺印重则滞塞无成；财印紧贴互破 |
| 财星损印（坏印／制枭） | 身强印重或偏印夺食为病时，财可裁抑多余印星、促成现实落地 | 日主偏弱赖印生身／化杀时，财坏印／制枭反绝生源并可能兼党官杀 |
| 印制食伤（御伤／挫食） | 身弱食伤泄气太过，或伤官见官需印护官 | 身强需食伤吐秀、生财或制杀时，偏印夺食破路 |
| 建禄／月刃驾杀用财官 | 日主乘月令禄刃身强，以官杀制劫或食伤泄秀生财 | 禄刃无官杀食伤成顽强孤滞；官杀混杂或制刃太过 |

同一节点常身兼多职，须画清全部主要路线并比较净效果，再看大运如何改写胜负。

## 5. 六大格局常规检查要点

- **正官格**：先看是否纯而不杂杀、是否见伤官（有印护或财化否）、日主强弱能否任官，以及官星根气是否受冲刑。
- **财格**：先看日主能否任财（身弱财多喜比印，身强财轻喜食伤）、是否见比劫争夺（有官制或食化否）、以及财是否党杀攻弱身。
- **印格**：先看身印是否过旺（旺则需食伤泄秀或轻财损印，切忌母多子病、只吸不吐）；若印轻身弱，最忌贪财坏印，喜官杀生印或比劫护印。
- **食伤格**：先分清食神生财、食神制杀、伤官生财、伤官佩印、金水伤官见官（调候例外）等不同去路；严查身强弱、是否泄气太过、是否逢枭夺食而无财解、是否见官破格。
- **七杀格**：依次检查①七杀是否月令格神及得根来源；②财是否贴生党杀；③日主是身强、身杀两停还是杀重身轻；④阳干身弱能否承受食制，抑或须转印化杀；⑤印星是否得润有根（抑或坐燥土受财克而传力受阻）；⑥制杀与化杀并行时是否相碍。
- **建禄／月劫／阳刃格**：月令不立格神，另寻四柱透干会支之财官杀食为用；阳刃格独喜官杀制刃、不忌杀透，忌无制或财刃相搏。

### 附：财印并见（含偏财制枭／正财坏印）的通用分层检查

凡局中财星与印星并见，不可一概喊凶或一概喊吉，须分四层看清：

1. **关系与位置层**：财印是紧贴直克，还是中间隔有日主、官杀或比劫缓冲通关？
2. **力量与燥湿层**：财与印各自有根否？印是否同时受燥湿失调影响传力？
3. **全局承载层**：日主究竟是身强印重（喜财裁抑、把过度内收转为现实产出），还是身弱赖印（忌财破救应、兼忌财党官杀）？
4. **领域双面层**：即便在全局层财克印偏忌，其在局部显化层仍可能带来“现实兑现／市场需求挤压内修”的拉扯；反之亦然。只依本盘真实结构展开，不预设固定职业或经历剧本。
