## 1. 术语映射

| 原文术语 | 本 skill 的工作译名 | 说明 |
|---|---|---|
| 用神 | 古典月令用神 / 格神 | 原文“八字用神，专求月令”，通常是月令与日干配出的格局中心，不等于现代扶抑补救用神 |
| 相神 | 成格关键辅助节点 | “全局之格，赖此一字而成者”；不只泛指喜神 |
| 喜神 | 有利于当前格局路线者 | 必须说明喜在哪条作用链 |
| 忌神 | 破格、伤用或伤相者 | 不由十神名称固定决定 |
| 成、败 | 格局路线是否成立 | 观察格神、日主承载、制化和位置配合 |
| 救应 | 处理败因的再制化 | 药也可能再被合、制或导回病处 |
| 有情 | 多个节点顺而相成 | 不是情感评价 |
| 有力 | 各关键节点真实有根有势 | 有情而无力仍不足成高格 |
| 透清 | 支中喜用在岁运透干、显化 | 不是藏干从无到有 |

徐乐吾在凡例中又说“用神非尽出于月令”，属于评注者的扩展立场。回答时应并列说明，不能反写成沈原文已经使用现代补救用神定义。

## 2. 月令不是单独计分项

原文以月令立组织中心，但明确说年月日时都有损益之权；得时可能因重克而不旺，失时可能因根深而不弱。由此：

1. 先由月令确定季节场和格局问题。
2. 再检查各柱根气、透藏、来源、去路与受制。
3. 身强身弱是全局汇总后的承载力，不是只凭月令作出的结论。

原文把比劫比作朋友相扶，把通根比作有室家可住，强调“干多不如根重”。这个比喻承担力量机制，取象时须连同上下文保留，不可缩成“有根更强”。

## 3. 格局是一条组织路线

“专主提纲，然后将四柱干支字字统归月令以观喜忌”，意为同一十神组合放入不同月令格局，功能可能相反。例如：

- 偏印与食神同见，不必一概枭夺食；若月令结构需要泄身，可能另论。
- 煞、食、印同见，要先分辨是食制煞被印破，还是印格以煞生印。
- 财食同见，要区分财格逢食生与食神格生财。

因此格局不是旺衰的别名，也不只是一个标签；它决定每个字在当前任务中的职务与去路。

## 4. 成败救应与相神

判断顺序：

1. 月令格神是什么。
2. 四柱怎样使格成立或失败。
3. 成中是否带忌，败中是否已有救应。
4. 哪一个节点是“全局赖之而成”的相神。
5. 相神是否又被合、克、泄或改变去路。

相神不一定生格神，也可能合去伤格之物、制住破格之神或补齐会局。所谓“用神不一定是喜神”，往往就是把格神、救应节点和最终喜忌混成一个词造成的。

## 5. 合冲刑会是关系重排

《真诠》对刑冲会合的重点不是列固定吉凶，而是观察一组关系怎样解开、重新释放或转移另一组关系：

- 合会可以使原冲暂不直接作用。
- 原本用于解冲的支又参加另一会局时，先前的冲可能重新出现。
- 另一个刑冲也可能牵住原来冲月令的字，从而保护格局中心。

所以不能只写“某支冲某支”。应画出各支当前去向，以及新增一支后哪条边被占用、哪条边被释放。

## 6. 三合会局会改变去路

原文不只把三合看作加总同一五行，还把它视为月令内部功能发生变化。例如寅月原可论伤官或月劫，遇午戌成火局后，原先的木气被组织到食伤/财的路线中，再看透干承接。

这支持“聚拢”和“力量改道”两层理解：

- 聚拢：多个支围绕同一旺支或局气集中。
- 改道：原本各支各自承担的根、格神或制化任务，转而服务成局后的五行。

聚拢本身不等于有利。成局五行是药，则做功集中；是病，则全局资源被集中去加重问题。是否完全化局仍须看月令、透干、根气、齐全度和原五行是否保留。

## 7. 墓库冲的严格边界

原文明确反对“辰戌丑未一冲就把所有库气放出”的通则：

- 四墓终以土为主，冲首先是土动。
- 当财官本身属土时，土冲可以表现为相关土气被发动；若戊己已透，未必还需冲。
- 当所取财官是墓中水木金火时，冲动土可能反而发动克制它的土，损伤原先透出的财官。
- 因此“两个库互相激发”只能作为现象候选，必须继续问：激发的是土本气、哪一藏干，还是原本藏干之间的冲突。

原文仍承认四墓之冲与子午卯酉的直接冲克性质有别，可优先称“冲动”，但不能由此推成“一冲皆开库”。

## 8. 位置与生克先后

相同财、官、食、枭并透，年、月、时的排列不同，可能形成“先破后救”或“先成后破”。原文并以隔位说明某干不能越过中间节点直接合克另一干。

操作时不仅记录距离权重，还要记录事件顺序：

- 前位先建立什么结构。
- 后位是在救前病，还是破坏已成结构。
- 中间节点是否截断、转流或保护目标。

这比“天干全部互相发生生克”更接近原文模型。

## 9. 调候是条件修正

原文坚持月令格局为主，同时用寒暖燥湿修正某条生克是否真的能完成。例如冻水未必能生木，燥土未必灵秀；金水伤官见官、夏木伤官佩印等会因调候需要形成常规规则的例外。

调候不等于另起一套不看格局的系统。当前 skill 应按以下顺序使用：

1. 先判结构关系存在。
2. 再检查季节气候是否使中间环节可工作。
3. 若调候急迫导致常规十神喜忌反转，明确写出反转条件。

## 10. 与现有 skill 的更新点

- 月令取格与全局承载力并行，但不得互相代替。
- “用神”强制标明原文词义、徐评扩展词义或现代功能词义。
- 地支合冲从静态配对升级为关系占用、释放与改道网络。
- 墓库冲不再泛称“开库”，先判土动及具体受影响藏干。
- 位置不仅表示远近，还表示先成后败或先败后救。
- 所有具体取象必须读取完整原文/评注展开；本文件只能用于模型定位。
