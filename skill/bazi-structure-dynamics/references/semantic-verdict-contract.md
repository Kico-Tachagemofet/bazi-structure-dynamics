# 八字现实断语合同

## 目标

完整断盘必须把结构转成现实判断。读者应能看出：

- 这个领域大致达到什么层级；
- 主要依靠什么十神链、动作和现实载体成事；
- 同一优势带来什么责任、消耗或冲突；
- 哪些条件改变结果、持续性或载体；
- 哪些判断最强，哪些只是次选。

性格、建议、技术标签和流程说明只能辅助解释，不能代替现实结论。

## 断语层级

按证据允许的最高层自然下判断：

1. 结果层级，例如学历深浅、专业化、权责、收入留存、关系稳定；
2. 领域性质，例如技术、制度、经营、研究、照护；
3. 动作与材料，例如精密操作、器械、切割、审查、测量、表达、交易、组织；
4. 一至三个相容的现实载体家族；
5. 具体身份或事件，只在组合高度集中时使用。

具体身份无法确定时，仍必须给出前四层中已经成立的方向，不能退回泛泛性格。

## 推导顺序

每个专题先看结构过程和十神链，再用天干、地支、藏干和柱位限定动作、场景、参与层与人事范围，最后判断现实结果。单一十神、单一干支或一个比喻没有独立直断权。

不同现实端点可以在散文中合写，但分析时必须能分辨学历、专业技术、资格权责、名声、收入、变动、关系结果和代价的方向。

## 岁运

岁运先继承原局，再判断新增干支怎样改变关系、通量、角色和载体。财、官杀、印、食伤运不能被机械翻译成就业、离校、任官或自由职业；须结合原局保证与现实阶段判断。

## 边界

- 客观成果能力与日主承载、轻松程度分开；
- 有利于病药制化不自动等于外部成就更高；
- 单一符号不直接锁定职业、疾病、人物或事件；
- 健康判断不替代现实诊断；
- 已知经历不得反向制造结构规则。
