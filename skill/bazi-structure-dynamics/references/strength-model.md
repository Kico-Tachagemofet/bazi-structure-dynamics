## 1. 分析单位

不要直接计算“木火土金水各几个”。把每个天干、每个地支藏干分别视为带柱位的节点，再根据共同五行和十神汇总。即使两个节点是同一个字，也先分别判断，例如“年支寅中甲”和“日支寅中甲”不可在第一步合并。

地支至少拆为：

- 本气：该支最主要、最稳定的作用源。
- 中气：条件具备时可起明显作用。
- 余气：潜伏作用，通常需得令、透出、成局或岁运引动才显著。

同一五行出现两次，不代表力量相等。月令本气、坐下强根与失令余气不能等量计数。

## 2. 八项证据

对每个节点记录以下证据：

| 维度 | 要问的问题 |
|---|---|
| 得令 | 在月令及司令下处于旺、相、休、囚、死的哪一层？ |
| 得地 | 是否坐禄旺、长生、墓库或同类根？根是本气还是中余气？ |
| 透藏 | 透干可直接参与天干作用；藏支较潜伏但不等于无效 |
| 来源 | 有没有印比、同党、三合方会或连续相生提供来源？ |
| 去路 | 力量是流向食伤、财、官杀、印，还是被阻塞？ |
| 受制 | 是否遭克、泄、耗、合绊、冲动或根被破坏？ |
| 位置 | 紧贴、同柱和月令优先；隔柱、遥隔降低直接性 |
| 引动 | 原局已经成立，还是必须等待透出、补齐、冲开、合入？ |

## 3. 月令与司令

- 月令是全局季节场，不只是月支中的一个字。
- 已知具体司令时，以司令校正月支内部本中余气的权重。
- 辰戌丑未不可一概当作同等的“土”：同时检查季节余气、库气、司令与冲合。
- 得令不保证最终强；失令也不保证最终弱。多根、多助、成局可以改变结论。

## 4. 根气与透藏

- 天干无根时，即使透出也可能浮；藏干得令有根时，即使不透仍能构成底层作用。
- 同柱坐根通常比隔支根直接；月令根通常比普通根重要。
- 藏干制化天干可以成立，但需要比较藏干层级、季节、数量、距离和是否被冲合。
- 透干的意义主要是显性、直接和易被岁运触发，不是从“零作用”变为“有作用”。

## 5. 日主承载力

最后才汇总日主：

1. 日主自身是否得令、得根、得助。
2. 生扶日主的印比是否真实可用，还是被财坏、被合、被冲或只是弱余气。
3. 财官食伤带来的克泄耗有多重，是否形成连续链。
4. 日主需要承担的格神有多强。
5. 日主弱时能否通过印化、比劫扶或通关恢复；强时能否通过食伤泄、财耗、官杀制而流通。

把身强身弱表达为“承载力”，例如：

- 偏强：能够承担财官食伤，但仍需出口。
- 偏弱：不能同时承受多重泄耗克，需要有效印比或通关。
- 身杀两停：日主与杀大致相称，可以考虑制杀取权。
- 杀重身轻：优先比较印化杀生身与扶身，不机械追加食伤泄身。
- 旺极/弱极：只在普通扶抑路线确实失效后讨论顺势或从格。

## 6. 结论语言

每个位置节点的力量判断都写成：

> 柱位与节点｜本中余气｜强/中/弱｜支持证据｜削弱证据｜原局可用度｜需要的引动条件

完成逐节点表后，再给五行与十神聚合强度。不要输出没有来源的百分比或总分。若证据相反，保留“中等但不稳定”“有根但受冲”“透而无根”等复合结论。
