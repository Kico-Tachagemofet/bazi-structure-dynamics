## 1. 三层资料结构

每一份来源都分成三层，后层不得替代前层：

1. **原始证据层**：保存原文或逐字稿、完整上下文、章节或页码/时间戳、命例及作者原有推理顺序。
2. **完整取象层**：把散落在正文、评注、命例和口头讲解中的象义汇集成展开卡，但不得删掉条件、动作链、相反表现和具体例子。
3. **规则索引层**：为了检索而写的短规则、关键词和分析步骤。每条必须反向链接原始证据层或完整取象层。

Skill 运行时可以先用规则索引定位，但凡要输出具体象义，必须继续读取完整取象层。只有规则索引、没有展开卡时，明确标为“尚未完成资料摄取”，不得凭常识或网络口诀自行补全。

## 2. 哪些内容必须保留展开版本

出现以下任一内容，均进入完整取象层：

- 天干、地支、藏干、五行的自然物象、空间、形态、动作和气候感。
- 十神对应的人物关系、心理倾向、行为模式、工作方式、职业和资源类型。
- 生、克、制、化、泄、耗、通关、合绊、冲动、刑害、墓库在现实中的过程和事件链。
- 性情、能力、学业、工作、财务、关系、身体、疾病、居所、出行等落地表现。
- 同一结构在强弱、得令失令、透藏、远近、成败太过不及下的不同表现。
- 命例中“为何取此象而不取彼象”的完整论证，以及失败例、反例和应期条件。
- 作者使用的比喻、画面和连续推演。比喻若承担机制说明，不得改成单个抽象标签。

例如来源若把某干支展开为多种材质、环境、动作和人物状态，不得只留下“某干支＝灵感”或“某冲＝规则变化”。短标签只可放在索引层。

## 3. 书籍与评注的摄取格式

按章或按一个完整论题建立资料块：

```markdown
## 主题

- 来源：书名、卷/篇/章、版本、页码或电子文本行号
- 层级：原文 / 评注 / 编者按 / 当前整理
- 流派：子平格局 / 旺衰扶抑 / 病药 / 调候 / 盲派等

### 原文或评注全文

保留该论点完整段落及必要的前后文。OCR 不确定字使用〔疑：X〕，不静默改字。

### 原文中的完整展开

- 原文列出的全部象义与例子
- 每个象成立的结构条件
- 相反条件下怎样变形
- 与前后段落的因果关系

### 命例

保留命造、原断、推理过程、应验事实及作者的归因，不只保留结论。

### 当前规则索引

短规则只写在这里，并链接回上面的完整材料。
```

原文和评注必须分栏。不得把评注者的解释改写成原作者立场，也不得把当前整理者的推论混进引文。

## 4. 课程与音视频的摄取格式

课程不得只依据标题或自动摘要入库。至少保存：

- 原始文件名、讲者、集数和时间范围。
- 带时间戳逐字稿；听不清处标记，不猜补。
- 去除纯口头停顿后的“清理逐字稿”。清理版可修复重复语气词，但不能合并或删除象义枚举、例子和推导步骤。
- 讲者明确规则、临时举例、命例演示和旁支象义分别标注。
- 与古籍不同的定义或断法单列为“课程体系差异”。

同一象在课程中反复从不同角度展开时，允许建立汇总卡，但原始时间戳片段全部保留，汇总卡逐项链接来源。

## 5. 取象卡格式

每张完整取象卡至少包含：

| 字段 | 内容 |
|---|---|
| 取象对象 | 单干、单支、十神、组合或作用链 |
| 来源与层级 | 谁说的；原文、评注还是课程讲解 |
| 基础形态 | 阴阳、五行、季节、方位、形质、动静 |
| 完整象义 | 人、物、事、空间、身体、心理、职业、行为，不删枚举 |
| 作用过程 | 它怎样生、克、泄、制、合、冲或转流 |
| 成立条件 | 得令、根气、透藏、位置、强弱、组合与引动 |
| 变形与反象 | 失令、受制、太过、不及或路线被截断时怎样表现 |
| 原始例证 | 原书命例、课程例子或明确回验 |
| 可用于本盘的范围 | 哪一部分已被力学判断支持；哪一部分只是候选 |

取象卡是“候选语义库”，不能倒过来证明格局或力量。先完成结构判断，再调用与有效节点、有效作用链相符的象义。

## 6. 流派与解释层隔离

每条材料必须标明来源体系：

- 子平月令格局
- 旺衰扶抑
- 调候
- 病药
- 盲派宾主体用/做功
- 其他简化或自定义体系

遇到同名异义时建立术语映射，不择一覆盖。例如古典“用神”、现代扶抑“用神”和功能补救“用神”分别保存。遇到十神阴阳定义、地支是否参与生克等根本假设不同的体系，分库存放，只能并列比较，不能拼成一条混合规则。

## 7. 压缩、改写与遗漏红线

- 不得用一句现代抽象话替换原文的连续画面和动作链。
- 不得只保留吉凶结论，删除“何时成立、何时反转”。
- 不得把多个不同领域的象合并成一个泛化人格标签。
- 不得删除看似重复但实为改变力度、对象或场景的例子。
- 不得把命例只摘成“某组合应某事”；必须保留作者从何处取象。
- 不得为了让规则整齐而消除作者内部矛盾。矛盾单列，等待跨章或命例复核。
- 不得用当前用户的个人经历补写通用象义。个人回验只提高特定链路在该个案中的显化置信度。

可以删除的只有不承载含义的版式噪声、重复页眉页脚及纯口头填充词；删除后不得改变语气强度、条件或推理顺序。

## 8. 摄取验收

完成一个章节或一集课程后逐项检查：

- [ ] 原文/逐字稿可以独立追溯到页码、行号或时间戳。
- [ ] 原文、评注、课程解释和当前归纳已分层。
- [ ] 所有象义枚举、比喻、动作链、命例和反例均已保留。
- [ ] 短规则全部能回链到展开材料。
- [ ] 流派标签和同名异义已经标明。
- [ ] 没有从缩略摘要二次推导象义。
- [ ] 随机抽取至少三个索引词，可以定位到完整上下文。
- [ ] 若来源存在 OCR/听写不确定项，已显式标记并安排回看原页或原视频。

任一与取象有关的前三层资料缺失时，该主题不得标记为“已摄取完成”。
