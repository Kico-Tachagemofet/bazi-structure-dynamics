# Report Scope

`report-scope.yaml` 只记录用户已经确认的范围，不保存答案或详细经历。

```yaml
chart_subject: self | proxy | named-subject
querent_role: self | proxy | unknown
subject_sex: female | male | unspecified
delivery_mode: full-natal | focused-topic | timing | synastry
topics: []
timing:
  major_luck: []
  years: []
explicit_questions: []
known_context_policy: isolated | allowed-for-manifestation | non-blind
```

## 确认门

“断一下、看看、分析一下”不构成完整 scope。信息不足时问一次：

> 这次想看完整原局，还是指定专题？要不要带大运或具体流年？如果涉及感情、六亲或子女，请补充命主性别以及本人／代看。

用户已经给出专题、时间范围和必要身份时直接记录，不重复询问。用户回答前不创建 scope 文件，也不自行增加感情、健康、子女或岁运。

“完整原局”默认指原局总论、家庭、学业、财运和事业；其他专题与时间范围按用户原话加入。
